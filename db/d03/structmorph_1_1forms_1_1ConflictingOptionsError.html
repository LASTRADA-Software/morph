Detailed Description

Thrown by schema generation when a Choice<…> member's FieldMeta also sets optionsAction: the member's type already names where its options come from, and two sources cannot both hold.

A programming error in the action's declaration, so a std::logic_error, thrown when the action registers. The fix is to drop optionsAction from the meta, or to make the member a plain type.

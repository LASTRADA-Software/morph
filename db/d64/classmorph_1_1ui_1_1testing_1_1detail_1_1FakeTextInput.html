Detailed Description

A fake TextInputWidget: properties mode, text, placeholder, and a text cursor.

The cursor is a byte offset into the text. A user's edit puts it where the edit left it; setText with the text the field shows leaves it alone, as the contract requires, and setText with another text puts it at the end.

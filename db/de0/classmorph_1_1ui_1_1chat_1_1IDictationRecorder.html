Detailed Description

Records a dictated clip from the device's microphone.

Each start ends in exactly one of: onStarted with an error, when recording could not begin (nothing follows); or onClip, possibly preceded by onStarted with success. A stop before recording began cancels the start, and is answered by onClip with an error. The callbacks run on the thread that owns the recorder. The interface sits in the UI layer, so what drives it is tested without a toolkit.

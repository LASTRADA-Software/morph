Detailed Description

The facts load-time validation needs from the application's catalog. Local mode answers them from the model registry in-process, the server at registration, a remote client from the UI service's catalog.

A lookup left empty skips the rules that need it: model the unknown-model and keyed-instance rules; action the unknown-action, wrong-model, refreshOn, optimistic and offline rules.

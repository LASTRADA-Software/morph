Detailed Description

Lists the runtime tours a server offers and keeps the list current.

list asks morph.tours.list. An answer makes the tours offered, loads each listed tour with loadTourText (one that does not load is logged at warn and left out), tells setOnListed's handler, and has the session watch the record morph.tours. A server that never registered the model answers unknown model type: morph.tours: the sync then offers none, which is logged once per sync at debug, since a server without runtime tours is ordinary. Any other failure is logged at warn and keeps the last list. While offered, a changes event naming the record, a resync and a reconnect list again. Neither copyable nor movable; on the runtime's owner.

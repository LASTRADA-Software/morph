Detailed Description

template<typename V, typename A, typename L>
struct morph::forms::Equals< V, A, L >

Condition: field's engaged value equals literal. An unengaged field is not vacuously satisfied here (unlike the comparison kinds) — a field with no value cannot equal anything, so equals returns false while the field is unengaged.

Template Parameters
VField member type.
AAction type the field belongs to.
LLiteral type (must satisfy RuleLiteral).

Detailed Description

Action guards: a check an action declares with using guard = ...;, which the framework runs on the decoded action on every execution site, after the validator and before Model::execute. This header adds the calls an application makes; the execution sites need only detail/action_guard_core.hpp. See docs/spec/core/action_guards.md.

template<typename Model, typename Action>
auto morph::model::executeChecked ( Model & model,
Action action )

Runs action on model as a dispatch would: recompute, the validator, the guard, then execute.

For a caller that holds a model directly — a unit test of a guard's outcome, server-side code running a model in process. A plain model.execute(action) runs no gate. There is no holder, so nothing is journaled and the guard is never skipped; a refusal reaches model.onGuardRefused when the model declares it.

Detailed Description

Answers the chat kinds, and runs each turn's loop on the worker: read what the screen offers, ask the provider, run the tools it calls, and repeat until it has no more.

Each tool call is an execute carrying the client's session, so it passes every check the GUI's own calls pass. It runs unscoped and names the instance the client's context gave, so it reaches the screen's own instance and leaves the connection's principal baseline alone. A running action therefore cannot be interrupted: cancelling a turn stops it between actions.

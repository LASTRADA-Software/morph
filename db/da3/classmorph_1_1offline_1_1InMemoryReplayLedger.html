Detailed Description

Thread-safe in-memory implementation of IReplayLedger.

Suitable for testing and for a host with no durability requirement. Mirrors morph::offline::InMemoryOfflineQueue's shape. Not durable across a process restart, and — since it is not backed by any real transaction — not a stand-in for record()'s atomicity requirement: a real implementation must be backed by the same store and transaction as the write it guards.

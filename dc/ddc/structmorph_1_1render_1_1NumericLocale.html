Detailed Description

The locale facts both control-edge conversions need, in one designated-initialisable aggregate.

Every member is defaulted to its "C"-locale spelling, so a default-constructed NumericLocale is the identity transform in both directions and a caller naming only the members it cares about gets the "C" spelling for the rest.

◆ zeroDigit

std::string_view morph::render::NumericLocale::zeroDigit = "0"

The locale's DIGIT ZERO, e.g. "\u0660". The ten digits are the ten code points contiguous from it. Empty, or not a well-formed UTF-8 code point, is read as the ASCII "0".

 A spacing step, 0 to kMaxSpacingStep, written as a literal: the strip and its rule span the node's width, the first tab starts this far in, and each page is padded by it on every side. A tabs node with it can be a page's edge-to-edge root. 0 writes none.
std::optional< int > pageInset
 A spacing step, 0 to kMaxSpacingStep, written as a literal, that pads each page in place of inset. A page that scrolls gives 0 and pads its own scrolled content, so that content's bleeding children reach the scroll's edges. Absent pads the pages by inset.

◆ Concurrency

enum class morph::reactive::Concurrency : std::uint8_t
strong

What a Mutation does with a run while another is in flight.

Enumerator
Exclusive 

Refuses the run: run() returns false and nothing is sent. The default: a second click on a pending button does nothing.

Serial 

Queues the run and sends it when the previous one settles, a failure included; one queue per MutationOptions::serialKey.

Latest 

Sends the run; only the newest run's reply is applied.

Parallel 

Sends the run; every reply is applied as it arrives.

◆ checkHandlerExecutor()

template<typename M, typename S>
void morph::reactive::detail::checkHandlerExecutor ( Runtime const & runtime,
bridge::BridgeHandler< M, S > const & handler )

Checks that handler delivers its callbacks on runtime's owner, reporting site::kHandlerExecutor when it does not.

A control node writes its signals from the handler's callbacks, so they must run where the runtime runs. The check is by affinity, not by pointer identity: a distinct serial executor that runs its tasks on the owner's thread is accepted. An executor that is not serial is reported at once. Any other serial executor is checked where it runs, by one posted task, which reports when it finds itself off the owner. No callback executor means the bridge's owner.

Template Parameters
MThe handler's model type.
SThe handler's sharing policy.
Parameters

handlerThe handler the node is built over.

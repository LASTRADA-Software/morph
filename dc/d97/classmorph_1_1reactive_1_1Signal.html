Detailed Description

template<typename T>
class morph::reactive::Signal< T >

A source value. Reading it with get() inside a tracked run subscribes that run.

set() skips a value equal to the current one when == is usable for T (kEqualityUsable) and the policy is EqualityPolicy::Auto; mutate() always notifies. Writes are refused, and reported, off the owner or inside a Computed. A read off the owner is reported and subscribes nothing.

T const & morph::reactive::Signal< T >::get ( ) const
inlinenodiscard

Reads the value, subscribing the innermost tracked run.

Off the owner the read is reported (detail::site::kOffOwner) and proceeds untracked: it subscribes nothing and leaves the tracking state alone. The value it returns is then read without synchronisation against the owner's writes.

Returns
The current value; valid until the next write.

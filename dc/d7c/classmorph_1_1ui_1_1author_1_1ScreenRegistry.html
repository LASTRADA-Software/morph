Detailed Description

The screens of an application, each validated once when it is registered.

Registration emits a screen's JSON once, loads it with loadDocumentText and the registry's catalog — the facts of every model and action the registered screens name, the screen's own first — and then runs checkAccessibility. A screen that fails is not registered.

template<std::invocable Make>
void morph::ui::author::ScreenRegistry::enroll ( Make const & make)
inlinenoexcept

Registers a screen and keeps its refusal rather than returning it, for registration at static initialisation, where nothing could report it; a server's test asserts refusals() is empty and lost() is zero.

Never throws, because its caller is a static initialiser, where an exception cannot be caught. A builder's own exceptions are already refusals; anything thrown while making the screen or keeping its refusal, such as an allocation failure, is counted by lost().

Template Parameters
MakeA callable that returns the Screen.
Parameters
makeMakes the screen; it is called inside the registration, so its exceptions are caught too.

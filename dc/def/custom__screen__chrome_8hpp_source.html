69/// @brief The window chrome of custom screens over one workspace, built from backend nodes so every frontend shows it.
70///
71/// For each document screen's tab, `chromeFor` gives a draft bar, shown while the tab holds a draft (Save for a draft
72/// of the person's own custom screen, Save as…, Source and Discard, and the last refusal of a save), and a row with
73/// the **Source** button, shown while it does not. **Source** opens the source view, an overlay with the document's
74/// JSON pretty-printed: read only while custom screens are not offered. **Preview** loads the text in the client, asks
75/// the server's `check`, and mounts what passes as the tab's draft (`DocumentScreenHost::mountDraft`); a refusal is
76/// shown with the line its pointer names, and choosing it moves the cursor there; the editor is read only while the
77/// check runs, so the draft is exactly the text previewed. **Save as…** asks a name, saves, and opens the saved screen
78/// in the tab's place. A reply to a save acts only on the draft that was saved: a tab that holds a newer draft, or
79/// none, keeps it and the person is told. **Remove**, on a screen of the person's own, asks once and removes it; a tab
80/// that showed it opens its base.
81///
82/// It is a view over a `CustomScreenController`, which holds every tab's draft and runs every command: the chrome
83/// draws the controller's state, and words its outcomes and refusals. Its fixed words are English; they are the
84/// view's, so localising them is the view's too. An application with controls of its own draws them over a controller
85/// of its own instead. Everything runs on the runtime's owner. Neither copyable nor movable.

272 // Wraps @p fn so it does nothing once the chrome is gone; posted closes and dialog presses can outlive it.
273 template <typename F>
274 [[nodiscard]] auto guarded(F fn) const {
275 return [alive = std::weak_ptr<bool>{_alive}, fn = std::move(fn)](auto&&... args) mutable {
276 if (auto const live = alive.lock(); live != nullptr && *live) {
277 fn(std::forward<decltype(args)>(args)...);
278 }

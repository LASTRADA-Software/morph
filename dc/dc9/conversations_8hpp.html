inlineconstexpr

What a transcribe request carries beyond the base64 audio, in bytes: the request body's own JSON (mediaType, the optional language, the framing) escaped once more inside the envelope, and the envelope's other fields, among them the session context. The session token has no bound in code, so the margin is the one the inline file cap leaves for the same envelope (kMaxInlineFileBytes), far above a signed token's few hundred bytes.

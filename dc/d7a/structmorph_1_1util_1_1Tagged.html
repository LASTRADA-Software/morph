template<typename T, morph::detail::FixedString Tag>
struct morph::util::Tagged< T, Tag >

An opaque, type-safe newtype wrapping a protocol scalar T, distinguished at compile time by the string tag Tag.

Template Parameters
TThe underlying wire scalar (e.g. std::string, std::int64_t).
TagA morph::detail::FixedString NTTP naming this newtype (e.g. "UserId"); part of the C++ type, never part of the wire.

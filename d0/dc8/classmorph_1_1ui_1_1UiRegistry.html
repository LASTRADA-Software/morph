Detailed Description

Collects an application's screens and files and builds the bundle the UI service serves.

Built once, before the service answers anything; build copies everything into an immutable ServedBundle. A screen authored with the C++ builders is added by its emitted text, so an authoring registry feeds this one through addScreen without either depending on the other.

Registers a screen: its catalog entry and its document.

Refused when the entry's id is empty, longer than kMaxNameBytes, already registered, or not the document's id; when whenDenied is neither hide nor disable; when the entry names a host (a host screen has no document: addEntry); when the document is app (addFile); when the text is too large to serve; and when load-time validation refuses the document.

std::expected< void, Refusal > morph::ui::UiRegistry::addFile ( BundleFile file)

Adds a file that is not a screen: the app document (app, whose id is app), a theme (theme), a message catalogue (messages), a delivered component (component) or an icon (icon).

Refused for another kind, an empty or over-long id, a kind and id already added, a file too large to serve, an app document that load-time validation refuses or whose id is not app, a message catalogue whose id is not i18n/LOCALE.json, that parseCatalogue refuses, or that has a pattern outside the ui/1 subset, and a theme file that is neither a theme index parseThemeIndex takes nor a token file parseTokens takes, and an icon that is not SVG text or is larger than kMaxIconBytes.

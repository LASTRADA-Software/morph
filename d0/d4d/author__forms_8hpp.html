Detailed Description

The collection and wizard builders that carry their forms documents (spec 5 §11): a view descriptor's v-* document and a wizard's w-* document go into the node's catalog facts, so the bundle serves them with the ui-catalog reply and a client builds the node without knowing the types. Separate from author.hpp so the builders that need no forms documents do not pull in the forms headers.

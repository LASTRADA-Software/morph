Detailed Description

The generic client as an MCP server on stdio (--mcp-stdio): remote over a WebSocket to a running server, or local over an in-process server on a linked application.

Specified in docs/spec/client/client.md and docs/spec/ui/agent.md.

The session an MCP server's calls carry.

The principal is --user, and in remote mode MORPH_MCP_PRINCIPAL when --user is not given. The token is MORPH_MCP_TOKEN, remote mode only: a local server checks no token, and a diagnostic says so when one is set.

Parameters
argsThe client's options.
environmentReads an environment variable; null for one that is not set.
diagnosticsWhere a token a local server ignores is reported.
Returns
The session.

Serves MCP on input and output until input ends.

Parameters
argsThe client's options: --server selects remote mode, --app local mode.
appsThe applications this client links, for local mode.
sessionThe session every call carries.
inputWhere JSON-RPC messages arrive, one per line.
outputWhere replies go, one per line, and nothing else.
diagnosticsWhere problems are reported.
Returns
The process exit code: 0 once input ended; 2 when the application is not linked, its bundle does not build, or its setUp throws; when neither --server nor --app is given; when the --server URL is not ws:// or wss://; or when no built transport can reach it.

Sets the process's stdout aside as the JSON-RPC channel: duplicates it, and points descriptor 1 at stderr, so anything else the process prints lands in the agent's log instead of corrupting the protocol.

Returns
The stream over the duplicate, or null when the descriptors cannot be duplicated.

29/// @brief The session an MCP server's calls carry.
30///
31/// The principal is `--user`, and in remote mode `MORPH_MCP_PRINCIPAL` when `--user` is not given. The token is
32/// `MORPH_MCP_TOKEN`, remote mode only: a local server checks no token, and a diagnostic says so when one is set.
33/// @param args The client's options.
34/// @param environment Reads an environment variable; null for one that is not set.
35/// @param diagnostics Where a token a local server ignores is reported.
36/// @return The session.
37[[nodiscard]] session::Context mcpSession(Args const& args, std::function<char const*(char const*)> const& environment,
38 std::ostream& diagnostics);

40/// @brief Serves MCP on @p input and @p output until @p input ends.
41/// @param args The client's options: `--server` selects remote mode, `--app` local mode.
42/// @param apps The applications this client links, for local mode.
43/// @param session The session every call carries.
44/// @param input Where JSON-RPC messages arrive, one per line.
45/// @param output Where replies go, one per line, and nothing else.
46/// @param diagnostics Where problems are reported.
47/// @return The process exit code: 0 once input ended; 2 when the application is not linked, its bundle does not
48/// build, or its `setUp` throws; when neither `--server` nor `--app` is given; when the `--server` URL is not
49/// ws:// or wss://; or when no built transport can reach it.
50[[nodiscard]] int serveMcp(Args const& args, std::vector<LocalApp> const& apps, session::Context session,
51 std::istream& input, std::ostream& output, std::ostream& diagnostics);
52
53/// @brief Sets the process's stdout aside as the JSON-RPC channel: duplicates it, and points descriptor 1 at stderr,
54/// so anything else the process prints lands in the agent's log instead of corrupting the protocol.
55/// @return The stream over the duplicate, or null when the descriptors cannot be duplicated.
56[[nodiscard]] std::unique_ptr<std::ostream> claimStdout();

Detailed Description

One action a view screen can fire — the row opener (v-rowAction) or an entry of v-actions.

Always built by describeAction<Action>(...), never constructed by hand, so actionTypeId always reflects a real, registered ActionTraits<Action>::typeId() rather than a hand-typed, unchecked string (contrast morph::forms::Choice's OptionsAction NTTP, which is an unchecked string — see docs/spec/forms/choice.md, "Limitations").

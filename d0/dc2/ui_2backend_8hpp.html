enum class morph::ui::RowClick : std::uint8_t
strong

How a click on a table row is modified, which decides what it does to the selection.

Enumerator
Only 

A plain click: only the row is selected, and it becomes the anchor.

Toggle 

Ctrl+click: the row is toggled, the rest kept, and it becomes the anchor.

Range 

Shift+click: the rows from the anchor to this one are selected, in place of the rest.

inlinenodiscard

A width in the vocabulary's units (what fixed(n) counts) as a width class: compact below 80 units, medium below kExpandedWidthUnits (108), expanded otherwise. Every backend classes its surface with it, so a document's breakpoints sit at the same number of its own units on every frontend.

Parameters
unitsThe width, in units: a terminal's columns, or a window's width over its unit width.
Returns
The class: compact, medium or expanded.

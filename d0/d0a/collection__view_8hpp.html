ui::Node morph::forms::collectionView ( CollectionSession & session,
CollectionViewOptions options = {} )
inlinenodiscard

Renders session: the header (title, busy indicator, collection actions), the error line, the rows as a table (visible columns' exact cells, then Open and the row actions), the confirm dialog, and the row editor (formView of editor()) as a dialog for a collection, or beside the table, shown while a row is open, for a master-detail view.

Test ids: collection_title, collectionAction_<Action>, collection_error, collection_rows, cell_<field>_<rowKey>, rowOpen_<rowKey>, rowAction_<Action>_<rowKey>, confirmDialog, confirm_message, confirm_accept, confirm_cancel, editorDialog and detailForm; the editor's fields have their form ids.

The nodes bind to the session by pointer: mount the result after the session and destroy the mount before it.

Parameters
sessionThe session.
optionsThe editor's form options, the chrome and the labels.
Returns
The view.

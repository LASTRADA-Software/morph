Detailed Description

Development reload (spec 5 §12): which documents a changed bundle changed, and remounting the mounted screens that show them, keeping their state.

A development client polls with UiClient::poll and hands each changed bundle to reloadDocuments. Specified in docs/spec/ui/service.md.

Loads the changed documents of a new bundle and remounts the mounted screens that show them.

Each changed screen document is loaded with options. A document that does not load is refused and keeps the old document, in documents and on every screen showing it. A document that loads is mounted, through DocumentScreenHost::remount, on every screen of mounted showing it, which keeps each state of the screen's own scope declared under the same name and type. A remount the interpreter refuses keeps that screen on the old document, and keeps the old document in documents. A changed id the bundle no longer holds, and the app document, which no DocumentScreenHost mounts, change nothing here.

Parameters
changedThe ids of the changed documents (changedDocuments).
bundleThe new bundle's documents.
optionsHow the documents load: the catalog facts.
documentsThe host's documents, updated in place.
hostThe host that mounted every screen of mounted.
mountedThe mounted screens.
Returns
The screens remounted, and the refusals.

Detailed Description

Runs a morph application in a Qt Quick window, on the calling thread.

run makes, in this order, the QGuiApplication (unless the process has one already), a qt::QtExecutor (the reactive runtime's owner and every bridge handler's callback executor), the runtime, a QtScheduler, the QML engine, the window and the backend, then runs the source through ui::runApp: it opens the source, mounts the shell through FrontendConfig::mountShell when the source is ready, and runs the event loop until AppContext::quit() or the window closes. Teardown is the reverse: the screens, then the source's connections, then the runtime, then Qt. The style is Qt Quick Controls' Basic; on the offscreen platform the window renders in software.

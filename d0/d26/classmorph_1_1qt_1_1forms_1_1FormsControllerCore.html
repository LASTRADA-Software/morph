template<typename Model>
class morph::qt::forms::FormsControllerCore< Model >

Owns the Bridge/BridgeHandler/executor plumbing behind a schema-driven QML forms controller, generic over the model type.

Executes optionsAction with bodyJson to fetch a Choice field's combo-box options, via the same generic executeJson path submitIfValid uses – optionsAction is never hardcoded, unlike the pre-factoring example controller, and bodyJson is a true pass-through (not always "{}"), so a dependent Choice (x-optionsDependsOn) can send {parentField: value, ...} instead of an empty body.

Template Parameters
OnReplyCallable invoked with the options-action result JSON on success.
OnErrorCallable invoked with the std::exception_ptr on failure.
Parameters
optionsActionRegistered action type id that serves the options.
bodyJsonFully-assembled JSON body for the options action ("{}" for an independent Choice).
onReplySuccess callback.
onErrorFailure callback.

How a model alias binds its instance (spec 5 §5).

Enumerator
Default 

None named: shared when the catalog marks the model stateless, private otherwise.

Private 

An instance of the scope's own, released when the scope unmounts.

Shared 

A stateless model's instance, its queries cached with other screens'; refused for a stateful model.

Keyed 

The shared instance an expression's key selects.

Borrowed 

The opener's binding of an alias ({"from": alias}), for a screen opened as a dialog.

◆ loadDocument()

std::expected< Document, Refusal > morph::ui::loadDocument ( Json const & json,
LoadOptions const & options = {} )
inlinenodiscard

Parses a UI document and runs its load-time validation (spec 5 §3).

A document is refused when it does not parse, when a reference does not resolve, when a type does not check, when the let or watch graph has a cycle, when an expression exceeds 256 nodes, when a node kind, command or function is not in ui/1, when a must-understand key is unknown, or when a rule of spec 5 or spec 6 fails; the list is in docs/spec/ui/document.md. The rules that need catalog facts run when options supplies them.

Parameters
jsonThe document's JSON.
optionsThe catalog facts.
Returns
The document, or the first refusal, naming the document id, the JSON Pointer and the reason.

◆ loadDocument()

LoadOptions const & options = {} )
inlinenodiscard

Parses a UI document and runs its load-time validation (spec 5 §3).

A document is refused when it does not parse, when a reference does not resolve, when a type does not check, when the let or watch graph has a cycle, when an expression exceeds 256 nodes, when a node kind, command or function is not in the vocabulary, when a document declares invalidates, patch or refreshOn, when a must-understand key is unknown, or when a rule of spec 5 or spec 6 fails; the list is in docs/spec/ui/document.md. The rules that need catalog facts run when options supplies them.

Parameters
jsonThe document's JSON.

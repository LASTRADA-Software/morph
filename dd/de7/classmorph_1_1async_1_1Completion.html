Detailed Description

template<typename T>
class morph::async::Completion< T >

Move-only handle representing the eventual result of an asynchronous operation.

Callbacks are posted to the IExecutor supplied at construction time, so they always run on the intended thread (e.g. the GUI thread).

Template Parameters
TType of the success value.
Thread safety
then() and onError() may be called from any thread. The registered callbacks are invoked via the executor, never directly from the producing thread.
Orphan detection
If a Completion is destroyed before an onError() handler is attached and the operation has already failed, the exception is logged as an orphan error.

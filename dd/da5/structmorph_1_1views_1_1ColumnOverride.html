Detailed Description

Declare-to-override entry for one derived column of a collection view.

Supplying a static constexpr std::array<ColumnOverride, N> columns on a view descriptor reorders, relabels, hides, or subsets the columns viewSchemaJson would otherwise derive from the query's row type; a field naming a wire key the row type does not have is emitted as a bare column (schema generation never throws — see docs/spec/forms/forms.md).

Detailed Description

The file side channel's store (files/1, spec 6 §18): uploads in chunks, and files a principal may read by a capability reference.

enum class morph::ui::FileError : std::uint8_t
strong

Why a store refused a call.

Enumerator
NotFound 

No such upload or file for this principal; a caller cannot tell the two apart.

TooLarge 

The file is larger than the store accepts.

OverQuota 

The principal's files would exceed what the store keeps for one principal.

BadOffset 

A chunk does not start where the bytes received so far end.

Incomplete 

An upload ended before every byte it announced arrived.

◆ newFileRef()

std::string morph::ui::newFileRef ( std::string_view prefix = "file:")
inlinenodiscard

A new unguessable id: prefix, then 32 lower-case hex digits read straight from std::random_device.

std::random_device is read directly, never used as a seed: libstdc++, libc++ and MSVC back it with the operating system's entropy source, which is what makes the id a capability.

Parameters
prefixfile: for a reference, upload: for an upload id.
Returns
The id.

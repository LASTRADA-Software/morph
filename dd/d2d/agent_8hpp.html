Detailed Description

The MCP adapter (spec 8 §11): an agent's tool calls run through the server as ordinary envelopes on a connection of their own, so every check a GUI gets applies to them, and every GUI watching what they change is told. The adapter speaks MCP's JSON-RPC 2.0 and knows no transport; serveStdio drives it over MCP's stdio transport.

void morph::ui::serveStdio ( McpAdapter & adapter,
exec::MainThreadExecutor & owner,
std::istream & input,
std::ostream & output )
inline

Serves an adapter over MCP's stdio transport: one JSON-RPC message per line of input, each reply on a line of output, in order, until input ends. An empty line is skipped.

The calling thread is the adapter's owner: it pumps owner while it waits for each reply.

Parameters
adapterThe adapter; its McpOptions::callbacks is owner.
ownerThe adapter's owner, run on the calling thread.
inputWhere messages arrive.
outputWhere replies go; flushed after each.

19/// @brief Builds every widget of a mounted view tree as a `core::tui::Component` on one `Screen`.
20///
21/// Containers arrange their children in cells when the screen renders them; a Dialog and an open Dropdown are
22/// screen overlays; drag-and-drop runs on the mouse with pointer capture. The factories, documented on
23/// `ui::IViewBackend`, run on the screen's thread. Widgets must be destroyed before the backend, and the backend
24/// before the screen.
25///
26/// The widgets show no tooltips, so nothing here needs the screen's hover timer (`Screen::tickHover`). A widget that
27/// goes drops the screen's hover target, so a caller that does tick it never reaches a destroyed component.
28class Backend final : public ui::IViewBackend {
29public:
30 /// @brief Reads the current time.

32
33 /// @param screen Where every widget renders. Borrowed: it must outlive the backend.
34 /// @param now The clock the widgets read the time from (a table telling a double click from two clicks); empty
35 /// reads `std::chrono::steady_clock`. A test passes one it advances itself.
36 explicit Backend(::core::tui::Screen& screen MORPH_LIFETIMEBOUND, Clock now = {});
37 /// @brief Destroys the backend; every widget it made must already be gone.

virtual int morph::ui::Frontend::run ( AppSource & source)
pure virtual

Builds the runtime and its executor, opens source, mounts the app shell and drives the loop until AppContext::quit.

Tears down in reverse: the screens, then the source's connections, then the runtime, then the loop and the toolkit. A frontend leaves the first two to runApp, which fixes that order, and keeps the rest by declaring its members or locals in construction order.

Parameters
sourceWhere the screens and the models are; it outlives the call.
Returns
The exit code passed to quit; a frontend may also end the run on its own (end of input, an interrupt) with a code it documents.

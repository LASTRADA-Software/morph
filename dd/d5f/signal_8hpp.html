◆ kEqualityUsable

template<typename T>
bool morph::reactive::kEqualityUsable = detail::EqualityUsable<std::remove_cv_t<T>>::value
inlineconstexpr

Whether == is usable for T, which is what the EqualityPolicy::Auto skip needs.

Checked through element types, not by std::equality_comparable alone: a standard container declares == for any element type, and comparing two of them fails to compile when the element has none. A type for which this is false always notifies.

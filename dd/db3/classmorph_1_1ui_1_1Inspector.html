Detailed Description

The development inspector over one mounted screen: its mounted nodes, its queries and mutations, the command lists it ran, and the reactive runtime's counters.

Every read returns a copy, so nothing it hands out writes the screen. The one thing it does to the screen is refetch, which runs the document command {"refetch": "<query>"} as a user's event would. Valid while the screen lives; use it on the runtime's owner.

std::vector< InspectedNode > morph::ui::Inspector::nodes ( ) const
inlinenodiscard

Every node of the screen whose scope is alive, in the order it was lowered (a parent before its children), each with its expression properties evaluated now.

A node is listed once per scope it was lowered in, so a row's nodes are listed once per row. A switch's default and a custom node's fallback are lowered in their enclosing scope, so they are listed whether or not they are shown. An evaluation the inspector makes reports no diagnostic.

Returns
The nodes.

std::vector< InspectedQuery > morph::ui::Inspector::queries ( ) const
inlinenodiscard

Every query and mutation of the screen's live scopes, the screen's own first, then those of the app document, with their state now.

A query is idle with no cache entry (its when is not true, its alias is unbound or its body is null), and with an entry that has neither a value nor a request; pending while a request is in flight; error when the last request failed; stale when its entry was invalidated or its value is at least staleTime old; fresh otherwise. A mutation is pending while a run is in flight or queued, error when its last run failed, fresh once a run succeeded, and idle before any.

Returns
The queries and mutations.

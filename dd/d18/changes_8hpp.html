◆ deriveChanges()

Changes morph::effects::deriveChanges ( std::string_view actionId,
std::string_view resultJson,
InstanceChange const & ranOn )
inlinenodiscard

The changes a successful execute made, from the action's declared effects and its result.

updates<R> gives the keys of the R rows found in the result, changes<R> the whole type, and both also every record derived from R, directly or through others, as a whole-type change. changesInstance gives ranOn. An action that declared nothing, or only none, gives no changes.

Parameters
actionIdThe action's id.
resultJsonThe action's result as JSON.
ranOnThe instance the action ran on.
Returns
The changes; empty for a reader.
Exceptions
morph::model::EffectsRegistrationErrorwhen the registered configuration is invalid.

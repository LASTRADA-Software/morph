Detailed Description

Abstract executor interface.

Concrete implementations decide where and when posted tasks run (thread pool, main thread, Qt event loop, …).

Schedules task for asynchronous execution.

Thread-safe. The task is invoked at some point after this call returns. Any exception thrown by the task is silently swallowed unless the implementation documents otherwise.

Detailed Description

template<typename Model>
class morph::bridge::BridgeHandler< Model >

RAII wrapper that binds a single model type to a Bridge.

On construction, registers a HandlerBinding on the bridge. On destruction, deregisters it automatically. The handler is non-copyable.

Fielded actions and subscriptions
Beyond the one-shot execute(action) -> Completion<R> API, the handler offers a streaming surface for actions whose values arrive field-by-field from a GUI (typically one widget per field):
  • subscribe<A>(cb) stashes a result callback for action type A.
  • set<&A::field>(value) updates one field of the in-progress draft of A.
  • unsubscribe<A>() drops the callback.
  • reset<A>() discards the in-progress draft of A.

◆ routeOf() [1/2]

std::expected< std::string, std::string > morph::ui::routeOf ( std::string_view screen,
std::vector< std::pair< std::string, Type > > const & declared,
ValueRecord const & params )
inlinenodiscard

Writes the route of a screen instance: its id, then each param the screen declares that params gives, in declaration order, as name=value joined by & after a ?.

A param's value is the canonical text of its declared type: an int in decimal, a bool as true or false, a decimal as num/den@dp (the canonical fraction and the places), a key as i:<int64> or s:<text>, and a string percent-encoded (every byte but RFC 3986's unreserved characters). A null or absent optional is left out. quantity, timestamp, list and record params have no route form.

Parameters
screenThe screen id.
declaredThe screen's declared params (Document::params), in order.
paramsThe params of this instance.
Returns
The route, or why the instance has none: a param of a type with no route form, a required param that is missing or null, or a value that does not have its declared type.

Detailed Description

Thread-safe in-memory implementation of IActionLog.

Suitable for testing and for applications that do not need cross-process durability. Mirrors morph::offline::InMemoryOfflineQueue's shape. Dedups append() on a non-empty LogEntry::idempotencyKey — see IActionLog's class docs.

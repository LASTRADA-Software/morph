Detailed Description

The application's side of the commands a document host does not answer itself (spec 6): sign-in and sign-out, which install a principal into the source, and the file commands, which read a picked file from disk and save a downloaded one, moving the bytes over the source's file side channel or inline.

A shell of an application's own builds one and passes it as DocumentScreenHostOptions::application; mountShell builds its own.

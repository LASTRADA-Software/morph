Detailed Description

IExecutor implementation that posts tasks to the Qt event loop.

Uses QMetaObject::invokeMethod with Qt::QueuedConnection so the callable always runs on the thread that owns QCoreApplication (typically the GUI thread).

Thread-safe: post() may be called from any thread. No QObject subclass is required by the caller.

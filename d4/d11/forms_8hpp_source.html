5/// @file forms/forms.hpp
6/// @brief JSON-Forms-style schema generation for morph actions.
7///
8/// Given an action type `A` (a plain aggregate, as registered with
9/// `BRIDGE_REGISTER_ACTION`), this header produces a standard JSON Schema a
10/// client can render a form from at runtime — the "describe" half of an
11/// auto-generated GUI. It builds on glaze's `write_json_schema` (which
12/// already contributes types, `$defs`, per-field metadata declared via
13/// `glz::json_schema<A>`, and the `ExtUnits` stamped by
14/// `morph::units::Quantity`) and closes the two gaps glaze leaves open:
15///
16/// - **`required`** — glaze's schema writer emits no `required` array at
17/// all. `schemaJson<A>()` derives one: a member is *required* unless it is
18/// a `std::optional<...>` or its name is listed in the action's opt-out
19/// list (see below).
20/// - **`x-decimalPlaces`** — for `Quantity` members, the unit's default
21/// decimal count from `UnitTraits`, so a client knows the input step
22/// without hardcoding unit knowledge.
23/// - **`x-order`** — the member's declaration index on every property, so a
24/// renderer can lay fields out in declaration order (JSON object key order
25/// is not reliable once schemas pass through DOMs/maps).
26/// - **`x-unitAlternatives`** — for `Quantity` members whose unit system
27/// declares convertible units (`UnitTraits<E>::relations`): an array of
28/// `{id, display, decimals, num, den}` entries, where `num/den` is the
29/// exact alternative-to-canonical ratio. Renderers offer a unit selector
30/// and recalculate entered values exactly on switch; payloads always carry
31/// the canonical unit.
32/// - **`x-optionsAction` / `x-optionValue` / `x-optionLabel`** — for
33/// `morph::forms::Choice` members: which registered action serves the
34/// options, and which result-row fields carry the submitted value and the
35/// display label. Renderers turn these into combo boxes populated by
36/// executing the named action.
37/// - **`x-optionsDependsOn`** — for a `Choice` whose options are
38/// parameterised by sibling field values (`Choice`'s `DependsOn` pack): the
39/// wire names of those sibling fields. Renderers send `{name: value, ...}`
40/// as the options-action request body instead of an empty one, and
41/// re-fetch when a named field changes. Omitted when the `Choice` declares
42/// no dependency.
43/// - **`x-layout` / `x-group` / `x-section` / `x-colspan`** — for actions
44/// declaring a `static constexpr` `formLayout` and/or `fieldSpans`
45/// (`morph::forms::FieldGroup` / `FieldSpan`, `forms/layout.hpp`): visual
46/// structure (sections, tabs, an accordion) over the flat field list, and
47/// per-field grid column spans. Absent either declaration, none of these
48/// keys are emitted and a renderer lays fields out exactly as it does
49/// today.
50/// - **`x-widget`** — for a field whose type declares a `noexcept static
51/// constexpr widget()` (`Multiline`, `Ranged` — widget_hints.hpp), or any
52/// field named in a `fieldMetadata`-shaped override: the renderer's
53/// preferred control id (`"textarea"`, `"slider"`, `"radio"`, …).
54/// - **`x-min` / `x-max` / `x-step`** — for a field whose type additionally
55/// declares `min()`/`max()`/`step()` (the `Ranged` shape): the slider's
56/// control-track bounds and increment — advisory, not a validation bound.
57/// - **`x-rules`** — for an action declaring a `static constexpr formRules`
58/// (`morph::forms::ruleList(...)`): a closed, typed cross-field rule
59/// vocabulary (`requiredWhen`, comparisons, membership, presentation)
60/// evaluated identically by the schema, the client, and the server. See
61/// `morph::forms::allRulesSatisfied` below and docs/spec/forms/forms.md.
62/// - **`x-computed` / `x-readonly`** — for a member listed as the destination
63/// of an action's `computedFields` declaration: the field is derived from
64/// sibling inputs (named in `x-computed.inputs`) and must not be rendered as
65/// an editable control (`x-readonly: true`). See `morph::forms::computed`,
66/// `morph::forms::computeList`, and `morph::forms::recomputeAll`.
67///
68/// `morph::time::Timestamp` members need no extension keys: their schema
69/// carries the standard `"format": "date-time"` annotation.
70///
71/// **Nested aggregates (recursive, cycle-guarded).** A member whose type is
72/// itself a reflectable aggregate — a plain nested struct, or
73/// `std::vector<Sub>` — gets its own members annotated too: `x-order`,
74/// title/`FieldMeta`, `required`, and the `Quantity`/`Choice`/widget/
75/// ranged-bounds rules above, applied against the nested type's own
76/// reflection. Unlike the top level, this recurses to whatever depth the
77/// type graph actually has, stopping only at a genuine cycle (a self- or
78/// mutually-referential nested-aggregate type), which is a compile-time
79/// `static_assert` rather than infinite recursion. Computed fields/
80/// `formLayout`/`fieldSpans`/`formRules` remain top-level-only regardless of
81/// depth. See docs/spec/forms/forms.md, "Nested aggregates (recursive,
82/// cycle-guarded)", and `detail::annotateNestedAggregateRef`.
83///
84/// @par Declaring optional fields
85/// Required is the default. An action opts individual fields out with a
86/// static member list:
87/// @code{.cpp}
88/// struct RecordMeasurement {
89/// std::int64_t sampleId = 0;
90/// Density density{};
91/// Moisture moisture{}; // may stay empty
92///
93/// static constexpr std::array optionalFields{std::string_view{"moisture"}};
94/// [[nodiscard]] bool validate() const { return morph::forms::allRequiredEngaged(*this); }
95/// };
96/// @endcode
97///
98/// @par Declaring computed fields
99/// A derived, read-only field is declared with a `static constexpr` map from a
100/// destination member to its declared input members and a pure derivation:
101/// @code{.cpp}
102/// struct LineItem {
103/// Quantity<Units, 2> qty;
104/// Quantity<Units, 2> price;
105/// Quantity<Units, 2> total; // computed -- not user-entered
106///
107/// // A generic (auto) lambda parameter: this initializer runs while
108/// // LineItem is still an incomplete type, so the body's member access
109/// // must stay dependent until first use, after the class is complete.
110/// static constexpr auto computedFields = morph::forms::computeList(
111/// morph::forms::computed<&LineItem::total, &LineItem::qty, &LineItem::price>(
112/// [](const auto& s) { return s.qty * s.price; }));
113/// };
114/// @endcode
115/// `schemaJson<A>()` then emits `x-computed`/`x-readonly` on `total` and
116/// excludes it from `required`; `recomputeAll<A>(action)` is the single
117/// evaluator the reactive `set<>` path and every dispatch path call to
118/// overwrite it authoritatively -- see `bridge.md`/`registry.md`.
119///
120/// @par Readiness helper
121/// `allRequiredEngaged(action)` returns `true` when every *required*
122/// empty-capable member (`Quantity`, `Choice`, `Timestamp` — anything with a
123/// `hasValue()`) is engaged. Wire it up as the action's `validate()`
124/// (the existing `ActionValidator` machinery picks that method up
125/// automatically) so the same declaration drives the schema's `required`
126/// array, the client-side submit gate, and the fielded-action readiness
127/// check. Non-quantity members are not checked — a plain `int64_t` cannot
128/// express "not filled in"; use a `Quantity` (or a custom `validate()`) when
129/// that distinction matters.

155/// @brief Per-field presentation overrides: label, help, placeholder,
156/// read-only, hidden (docs/spec/forms/forms.md, "Field metadata").
157///
158/// An action opts in with a `static constexpr std::array<FieldMeta, N>`
159/// (or, for the `describe<>()` sugar, a `static const` array defined
160/// out-of-line — see `describe()`'s documentation) named `fieldMetadata`,
161/// mirroring the existing `optionalFields` convention. Every member other
162/// than `field` defaults to "not declared": an empty `label`/`help`/
163/// `placeholder` means "infer the title, omit the rest"; `readOnly`/`hidden`
164/// default to `false`. `mergeSchemaExtras` looks up the entry (if any)
165/// matching each reflected member by wire key and patches the property node;
166/// an entry naming a field that does not exist on the action is ignored.
167struct FieldMeta {
168 /// @brief Wire key of the member this entry describes.
169 std::string_view field;
170 /// @brief Display label; empty infers a title-cased name from `field`.
171 std::string_view label{};
172 /// @brief Help text; empty omits `description`.
173 std::string_view help{};
174 /// @brief In-control placeholder hint; empty omits `x-placeholder`.
175 std::string_view placeholder{};
176 /// @brief Explicit message-key **stem** override for this field's i18n
177 /// catalog keys; empty means "derive the stem from the action's
178 /// `ActionTraits<A>::typeId()` and this field's wire key" (see
179 /// `morph::forms::i18n::fieldKey`, `forms/i18n.hpp`). A non-empty
180 /// stem replaces only the `<actionTypeId>.<wireField>` portion of
181 /// the key — the per-slot `.label` / `.help` / `.placeholder`
182 /// suffix is still appended on top of it (see
183 /// `morph::forms::i18n::explicitFieldKey`), so `"myKey"` expands
184 /// to `"myKey.label"` / `"myKey.help"` / `"myKey.placeholder"`,
185 /// never to a single complete key on its own. Emitted as
186 /// `x-i18nKey` only when non-empty.
187 std::string_view i18nKey{};
188 /// @brief Widget-selection override; empty means "use the field type's
189 /// own `widget()`, if any". A non-empty value replaces that
190 /// type-derived default and is emitted as `x-widget`
191 /// (docs/spec/forms/widget_hints.md). Read structurally by
192 /// `detail::widgetOverride`, not through this type by name — see
193 /// `detail::HasFieldMetadataWidgets`.
194 std::string_view widget{};
195 /// @brief Displayed but not editable when `true`; emits `x-readonly`.
196 bool readOnly{false};
197 /// @brief Not shown at all when `true`; emits `x-hidden`. The field still
198 /// travels in the payload (see `docs/spec/forms/forms.md`,
199 /// "Field metadata is not a security control").
200 bool hidden{false};
201
202 /// @brief Returns a copy with `placeholder` set to @p text.
203 /// @param text The placeholder hint.
204 /// @return The updated descriptor.
205 [[nodiscard]] constexpr FieldMeta withPlaceholder(std::string_view text) const noexcept {
206 FieldMeta copy = *this;
207 copy.placeholder = text;
208 return copy;
209 }
210
211 /// @brief Returns a copy with `readOnly` set to `true`.
212 /// @return The updated descriptor.
213 [[nodiscard]] constexpr FieldMeta withReadOnly() const noexcept {
214 FieldMeta copy = *this;
215 copy.readOnly = true;
216 return copy;
217 }
218
219 /// @brief Returns a copy with `hidden` set to `true`.
220 /// @return The updated descriptor.
221 [[nodiscard]] constexpr FieldMeta withHidden() const noexcept {
222 FieldMeta copy = *this;
223 copy.hidden = true;
224 return copy;
225 }
226};

228/// @brief Concept: a field type with an internal empty state (`Quantity`,
229/// `Choice`, `Timestamp`, or any user type exposing `hasValue()`).
230///
231/// `hasValue()` must be `noexcept`: `allRequiredEngaged` is `noexcept` and calls
232/// it on every member, so a throwing `hasValue()` would cross a `noexcept`
233/// boundary and call `std::terminate`. Requiring it here turns that into a
234/// compile-time rejection instead — a user field with a throwing `hasValue()`
235/// simply does not satisfy the concept.
236template <typename T>
237concept EmptyCapableField = requires(const T& field) {
238 { field.hasValue() } noexcept -> std::convertible_to<bool>;
239};

276/// @brief Concept: action declares a `static constexpr`/`static const`
277/// iterable `fieldMetadata` list of `FieldMeta` entries.
278///
279/// Constrained to `FieldMeta` elements specifically (not just "some iterable
280/// named `fieldMetadata`"): `findFieldMeta` below hands back a `const
281/// FieldMeta*`, so an action whose `fieldMetadata` holds a different element
282/// shape must not satisfy this concept — that shape may still be a valid
283/// *widget*-override source for `detail::HasFieldMetadataWidgets` /
284/// `detail::widgetOverride` (structural, `.field`/`.widget` only), which is
285/// deliberately independent of this concept.
286template <typename A>
287concept HasFieldMetadata = requires {
288 { *std::begin(A::fieldMetadata) } -> std::convertible_to<const FieldMeta&>;
289 std::end(A::fieldMetadata);
290};

292/// @brief Returns the `FieldMeta` entry naming @p fieldName in
293/// `A::fieldMetadata`, or `nullptr` if @p A declares no such list or
294/// no entry names @p fieldName.
295template <typename A>
296[[nodiscard]] const FieldMeta* findFieldMeta(std::string_view fieldName) noexcept {
297 if constexpr (HasFieldMetadata<A>) {
298 for (auto const& candidate : A::fieldMetadata) {
299 if (candidate.field == fieldName) {
300 return &candidate;
301 }
302 }
303 } else {
304 static_cast<void>(fieldName);
305 }
306 return nullptr;
307}

309/// @brief Splits @p fieldName on camelCase/underscore boundaries and
310/// title-cases each word (`dryMassPct` -> `"Dry Mass Pct"`,
311/// `sample_id` -> `"Sample Id"`, `notes` -> `"Notes"`).
312inline std::string inferTitle(std::string_view fieldName) {
313 std::string result;
314 bool startOfWord = true;
315 for (std::size_t i = 0; i < fieldName.size(); ++i) {
316 char const c = fieldName[i];
317 if (c == '_') {
318 startOfWord = true;
319 continue;
320 }
321 bool const isUpper = std::isupper(static_cast<unsigned char>(c)) != 0;
322 bool const prevUpper = i > 0 && std::isupper(static_cast<unsigned char>(fieldName[i - 1])) != 0;
323 if (i > 0 && isUpper && !prevUpper) {
324 startOfWord = true;
325 }
326 if (startOfWord && !result.empty()) {
327 result += ' ';
328 }
329 result += startOfWord ? static_cast<char>(std::toupper(static_cast<unsigned char>(c)))
330 : static_cast<char>(std::tolower(static_cast<unsigned char>(c)));
331 startOfWord = false;
332 }
333 return result;
334}

362/// @brief Concept: `A::fieldMetadata` entries additionally expose `.field` and
363/// `.widget`, both convertible to `std::string_view` — the shape
364/// `FieldMeta` (above) has. Checked structurally (duck-typed) so this
365/// header never has to include or name that type by name in this
366/// lookup: any descriptor array with the two members is honoured as a
367/// widget-override source, regardless of which header declares it.
368template <typename A>
369concept HasFieldMetadataWidgets =
370 HasFieldMetadataEntries<A> && requires(std::remove_cvref_t<decltype(*std::begin(A::fieldMetadata))> entry) {
371 { entry.field } -> std::convertible_to<std::string_view>;
372 { entry.widget } -> std::convertible_to<std::string_view>;
373 };

375/// @brief Returns the non-empty `widget` of the `A::fieldMetadata` entry whose
376/// `field` equals @p fieldName, or an empty view when `A` declares no
377/// `fieldMetadata` (or none of its entries name @p fieldName).
378template <typename A>
379[[nodiscard]] constexpr std::string_view widgetOverride(std::string_view fieldName) noexcept {
380 if constexpr (HasFieldMetadataWidgets<A>) {
381 for (auto const& entry : A::fieldMetadata) {
382 if (std::string_view{entry.field} == fieldName) {
383 return std::string_view{entry.widget};
384 }
385 }
386 } else {
387 static_cast<void>(fieldName);
388 }
389 return {};
390}

392/// @brief Invokes `visitor.operator()<I>(name, member)` for every reflected
393/// member of @p action (glaze pure reflection).
394template <typename A, typename Visitor>
395// NOLINTNEXTLINE(cppcoreguidelines-missing-std-forward, cppcoreguidelines-pro-bounds-avoid-unchecked-container-access)
396// — member-tie iteration
397constexpr void forEachNamedMember(A&& action, Visitor&& visitor) {
398 using Plain = std::remove_cvref_t<A>;
399 constexpr auto memberCount = glz::reflect<Plain>::size;
400 auto memberTie = glz::to_tie(action);
401 [&]<std::size_t... I>(std::index_sequence<I...>) {
402 // NOLINTNEXTLINE(cppcoreguidelines-pro-bounds-avoid-unchecked-container-access) — index bounded by
403 // reflect::size
404 (visitor.template operator()<I>(glz::reflect<Plain>::keys[I], glz::get_member(action, get<I>(memberTie))),
405 ...);
406 }(std::make_index_sequence<memberCount>{});
407}

409/// @brief Extracts the containing class type from a pointer-to-member type.
410template <typename T>
411struct MemberPointerClass;
412
413/// @brief Partial specialisation matching `Member Class::*`.
414template <typename C, typename M>
415struct MemberPointerClass<M C::*> {
416 /// @brief The pointer-to-member's containing class.
417 using type = C;
418};
419
420/// @brief Convenience alias for `MemberPointerClass<T>::type`.
421template <typename T>
422using MemberPointerClassT = typename MemberPointerClass<T>::type;
423
424/// @brief Resolves the wire key name of @p MemberPtr by comparing member
425/// addresses on a default-constructed probe of its containing type.
426///
427/// Deliberately **not** `constexpr`/`consteval`: glaze's `get_member` for
428/// reflectable (pure-reflection) aggregates is not itself constexpr, so this
429/// can only run at ordinary runtime — which is why `describe<>()` is a plain
430/// function and why a `fieldMetadata` array built from it must be defined
431/// out-of-line (see `describe()`'s documentation for why and how).
432template <auto MemberPtr>
433[[nodiscard]] std::string_view memberWireName() noexcept {
434 using A = MemberPointerClassT<decltype(MemberPtr)>;
435 A probe{};
436 std::string_view found{};
437 forEachNamedMember(probe, [&]<std::size_t I>(std::string_view name, auto& member) {
438 using MemberT = std::remove_reference_t<decltype(member)>;
439 using TargetT = std::remove_reference_t<decltype(probe.*MemberPtr)>;
440 if constexpr (std::is_same_v<MemberT, TargetT>) {
441 if (std::addressof(member) == std::addressof(probe.*MemberPtr)) {
442 found = name;
443 }
444 }
445 });
446 return found;
447}

506/// @brief Whether @p value counts as "engaged" for rule purposes:
507/// `hasValue()` for an `EmptyCapableField` (`Quantity`/`Choice`/`Timestamp`),
508/// otherwise `has_value()` for a plain `std::optional<T>` — the rule
509/// vocabulary treats both as "a field with an empty state", unlike
510/// `allRequiredEngaged` (which only inspects `EmptyCapableField`; a plain
511/// `std::optional<T>` exposes `has_value()`, not `hasValue()`, so it never
512/// satisfies that concept — see forms.md's "two exclusions" note). Only ever
513/// called on a type satisfying `EngageableField` (defined below), enforced
514/// by every public factory that calls it.
515template <typename T>
516[[nodiscard]] constexpr bool isEngaged(const T& value) noexcept {
517 if constexpr (::morph::forms::EmptyCapableField<T>) {
518 return value.hasValue();
519 } else {
520 return value.has_value();
521 }
522}

524/// @brief Resolves the wire (JSON) field name of @p field on `A`, the same
525/// way `x-order` is derived (`mergeSchemaExtras`): a fresh probe instance is
526/// walked with `forEachNamedMember`, matching by member address. `A` must be
527/// default-constructible (already required by `schemaJson<A>()`). Returns an
528/// empty string if @p field does not name a reflected member of `A` (should
529/// not happen for a pointer-to-member of `A` itself; defensive only).
530template <typename V, typename A>
531[[nodiscard]] inline std::string resolveFieldName(V A::* field) {
532 std::string found;
533 A probe{};
534 forEachNamedMember(probe, [&]<std::size_t I>(std::string_view name, const auto& member) {
535 static_cast<void>(I);
536 using Member = std::remove_cvref_t<decltype(member)>;
537 if constexpr (std::is_same_v<Member, V>) {
538 if (static_cast<const void*>(&member) == static_cast<const void*>(&(probe.*field))) {
539 found = std::string{name};
540 }
541 }
542 });
543 return found;
544}

558/// @brief The shared compile-time string used to capture an `equals` literal.
559///
560/// Aliased, not redefined: `morph::detail::FixedString` is the project's single
561/// canonical NTTP-capable fixed string (the forms `Choice` layer and the units
562/// layer already alias it too).
563///
564/// `equals(&A::code, "URGENT")` used to store its argument as a `std::string`,
565/// which quietly bounded the documented
566/// `static constexpr auto formRules = ruleList(...)` form to whatever fits the
567/// standard library's small-string buffer — 15 characters on libstdc++. One
568/// character more and the string allocates, so the rule node is no longer a
569/// constant expression and the declaration fails with "refers to a result of
570/// `operator new`". The limit is invisible in the source: the same code
571/// compiles or does not depending only on how long the literal is, and on which
572/// standard library is in use.
573///
574/// Holding the characters inline removes the allocation, so a literal of any
575/// length works. Passing an explicit `std::string` still stores a `std::string`
576/// (see `RuleLiteral`) and still cannot be `constexpr` when it allocates — that
577/// is inherent to the type the caller chose, not something this can fix.
578///
579/// @tparam N Literal length including its trailing NUL.
580template <std::size_t N>
581using LiteralString = ::morph::detail::FixedString<N>;

912/// @brief Constraint: literal types `equals(...)` accepts — the closed,
913/// JSON-representable scalar set a field can hold. Restricting the literal

915/// (see forms.md): a numeric literal is always the exact `math::Rational`,

917template <typename T>
918concept RuleLiteral = std::same_as<T, std::int64_t> || std::same_as<T, bool> || std::same_as<T, std::string> ||

921/// @brief Condition: `field`'s engaged value equals @p literal. An
922/// unengaged field is **not** vacuously satisfied here (unlike the
923/// comparison kinds) — a field with no value cannot equal anything, so
924/// `equals` returns `false` while the field is unengaged.
925/// @tparam V Field member type.
926/// @tparam A Action type the field belongs to.
927/// @tparam L Literal type (must satisfy `RuleLiteral`).
928template <typename V, typename A, typename L>
929struct Equals {
930 /// @brief Pointer to the member this condition inspects.
931 V A::* field;
932 /// @brief The literal to compare the field's engaged value against.
933 L literal;
934 /// @brief The wire `"kind"` this condition emits: `"equals"`.
935 static constexpr detail::RuleKind kind = detail::RuleKind::Equals;
936
937 /// @brief Evaluates the condition against @p action.
938 /// @param action The action snapshot to inspect.
939 /// @return `true` when the field is engaged (or has no empty state) and
940 /// its value equals `literal`.
941 [[nodiscard]] constexpr bool test(const A& action) const noexcept {
942 const auto& fieldValue = action.*field;
943 if constexpr (EngageableField<V>) {
944 if (!detail::isEngaged(fieldValue)) {
945 return false;
946 }

948 } else {
949 return static_cast<bool>(fieldValue == literal);

951 }

954 /// @return `{"kind":"equals","fields":["<wire name>"],"value":...}`,
955 /// where `value` is `{"num":...,"den":...}` for a `Rational`
956 /// literal and the bare scalar otherwise.
957 [[nodiscard]] glz::generic_u64 emitNode() const {
958 glz::generic_u64 node{};

976 }

978 }

1461/// @brief Evaluates one `ComputedField` against @p action, writing the result
1462/// into the destination member in place.
1463///
1464/// If every declared input is engaged -- or is not itself empty-capable, in
1465/// which case it is always considered engaged, mirroring `allRequiredEngaged`'s
1466/// treatment of non-empty-capable members -- the destination member is
1467/// overwritten with `field.fn(action)`. For a `Quantity` destination the
1468/// result is first converted to the destination's own type (same unit, the
1469/// destination's own `DeclaredDecimals`) and then retagged to that type's
1470/// declared precision (`Quantity::atDeclaredPrecision()`), so the stored value
1471/// matches the field's advertised `x-decimalPlaces` regardless of what
1472/// declared precision `Fn`'s return type happened to carry. If any declared
1473/// input is unengaged, the destination is instead reset to its
1474/// default-constructed (empty, for `Quantity`/`Choice`/`Timestamp`) value
1475/// rather than computed from a missing operand.
1476/// @tparam A Action type (a reflectable aggregate).
1477/// @tparam Dst Pointer-to-data-member of the destination field.
1478/// @tparam Fn Callable type of the derivation function.
1479/// @tparam Inputs Pointer-to-data-members of the declared input fields.
1480/// @param action Draft action whose destination member is overwritten in place.
1481/// @param field The declaration being evaluated.
1482template <typename A, auto Dst, typename Fn, auto... Inputs>
1483constexpr void recomputeOne(A& action, const ComputedField<Dst, Fn, Inputs...>& field) {
1484 bool allEngaged = true;
1485 [[maybe_unused]] auto checkInput = [&]<auto InputPtr>() {
1486 using InputMember = std::remove_cvref_t<decltype(action.*InputPtr)>;
1487 if constexpr (EmptyCapableField<InputMember>) {
1488 if (!(action.*InputPtr).hasValue()) {
1489 allEngaged = false;
1490 }
1491 }
1492 };
1493 (checkInput.template operator()<Inputs>(), ...);
1494
1495 using DstMember = std::remove_cvref_t<decltype(action.*Dst)>;
1496 if (!allEngaged) {
1497 action.*Dst = DstMember{};
1498 return;
1499 }
1500 auto result = field.fn(action);
1501 if constexpr (units::isQuantity<DstMember>) {
1502 DstMember const converted = result;
1503 action.*Dst = converted.atDeclaredPrecision();
1504 } else {
1505 action.*Dst = result;
1506 }
1507}

1653 using Bound = std::remove_cvref_t<decltype(Member::min())>;
1654 if constexpr (std::floating_point<Bound>) {

1656 property["x-max"] = static_cast<double>(Member::max());
1657 property["x-step"] = static_cast<double>(Member::step());
1658 } else {
1659 property["x-min"] = static_cast<std::int64_t>(Member::min());
1660 property["x-max"] = static_cast<std::int64_t>(Member::max());
1661 property["x-step"] = static_cast<std::int64_t>(Member::step());

1680/// @brief Recurses into @p property's own object schema if @p Member (or, for
1681/// `std::vector<Sub>`, its element type) is itself a
1682/// `ReflectableAggregate` -- the single decision point shared by
1683/// `mergeSchemaExtras`'s top-level loop and `annotateNestedAggregate`'s
1684/// own loop, so the cycle guard below has exactly one implementation.
1685///
1686/// @p Ancestors is the chain of nested-aggregate types already being
1687/// annotated on the current path, **including** the type that declares this
1688/// member (the caller appends its own `Sub`/`A` before calling this). If the
1689/// type to recurse into matches any entry already on that chain, recursing
1690/// further would eventually re-enter this same instantiation and try to do
1691/// so again -- forever. Rather than let that happen, a `static_assert` (whose
1692/// condition depends on @p Member and @p Ancestors, so it only fires for the
1693/// specific cyclic instantiation, not every use of this generator) rejects it
1694/// at compile time instead: a self-referential nested-aggregate type (e.g.
1695/// `struct Node { std::vector<Node> children; };`), or a mutual reference
1696/// between two distinct types, fails to build with a clear message rather
1697/// than exhausting the compiler's template-instantiation depth. This only
1698/// rejects genuine cycles -- the same type reused from two unrelated places
1699/// in the schema (a "diamond") is not on either path's ancestor chain and
1700/// recurses normally into both. See `docs/spec/forms/forms.md`, "Nested
1701/// aggregates (recursive, cycle-guarded)".
1702/// @tparam Member The static type of the member `annotateBasicMemberProperty`
1703/// was just applied to.
1704/// @tparam Ancestors The ancestor chain so far, ending with the type that
1705/// declares this member.
1706/// @param dom The whole schema DOM (so a `$ref`'s `$defs` entry can be found).
1707/// @param property The property node for this member (or, for `std::vector<Sub>`,
1708/// the property whose `"items"` node is the one to check).
1709template <typename Member, typename... Ancestors>
1710void recurseIntoNestedAggregateIfAny(glz::generic_u64& dom, glz::generic_u64& property) {
1711 if constexpr (ReflectableAggregate<Member>) {
1712 if constexpr ((std::same_as<Member, Ancestors> || ...)) {
1713 static_assert(!(std::same_as<Member, Ancestors> || ...),
1714 "morph::forms: cyclic nested-aggregate schema -- this member's type already "
1715 "appears in its own chain of enclosing nested-aggregate types (a self- or "
1716 "mutually-referential type). Recursion depth is otherwise unbounded, but cycles "
1717 "are not supported: restructure the domain type (flatten the self-reference, or "
1718 "represent the recursive edge as an opaque id instead of a nested value).");
1719 } else {
1720 annotateNestedAggregateRef<Member, Ancestors...>(dom, property);
1721 }
1722 } else if constexpr (IsStdVector<Member>::value &&
1723 ReflectableAggregate<typename IsStdVector<Member>::ValueType>) {
1724 using ItemType = typename IsStdVector<Member>::ValueType;
1725 if constexpr ((std::same_as<ItemType, Ancestors> || ...)) {
1726 static_assert(!(std::same_as<ItemType, Ancestors> || ...),
1727 "morph::forms: cyclic nested-aggregate schema -- this std::vector<Sub> member's "
1728 "element type already appears in its own chain of enclosing nested-aggregate "
1729 "types (a self- or mutually-referential type). Recursion depth is otherwise "
1730 "unbounded, but cycles are not supported: restructure the domain type (flatten "
1731 "the self-reference, or represent the recursive edge as an opaque id instead of "
1732 "a nested value).");
1733 } else if (property.contains("items")) {
1734 annotateNestedAggregateRef<ItemType, Ancestors...>(dom, property["items"]);
1735 }
1736 }
1737}

1739/// @brief Annotates @p node -- the object-schema DOM node for a
1740/// nested-aggregate member -- applying `required` and
1741/// `annotateBasicMemberProperty`'s rules to its own properties, then
1742/// recursing into any of *its* members that are themselves nested
1743/// aggregates (see `recurseIntoNestedAggregateIfAny`), to whatever
1744/// depth the type graph actually has.
1745///
1746/// @p node is @e which DOM node depends on how many places in the whole
1747/// schema reference `Sub`: glaze **inlines** the object schema directly into
1748/// the referencing property when `Sub` is used exactly once (so @p node
1749/// *is* that property node), but **deduplicates** via `$defs`/`$ref` when
1750/// `Sub` is used two or more times (so @p node is the shared `$defs` entry,
1751/// resolved by the caller). Both forms have the identical `{"properties":
1752/// {...}}` shape this function needs, so one implementation handles both --
1753/// see the call site in `mergeSchemaExtras` for how @p node is resolved.
1754///
1755/// Computed fields, `formLayout`/`fieldSpans`, and `formRules` stay
1756/// top-level-only regardless of depth; a nested `Sub` declaring any of those
1757/// has no effect here.
1758///
1759/// @tparam Sub Nested aggregate type (default-constructible, glaze-reflectable
1760/// -- the same requirements the top-level action type already has).
1761/// @tparam Ancestors The ancestor chain so far (excluding `Sub`); `Sub` is
1762/// appended before recursing into each of `Sub`'s own
1763/// members via `recurseIntoNestedAggregateIfAny` (see
1764/// that function's doc comment).
1765/// @param dom The whole schema DOM (so a deeper `$ref`'s `$defs` entry can be found).
1766/// @param node The object-schema DOM node to annotate in place (see above).
1767template <typename Sub, typename... Ancestors>
1768void annotateNestedAggregate(glz::generic_u64& dom, glz::generic_u64& node) {
1769 Sub probe{};
1770 glz::generic_u64::array_t requiredNames{};
1771 forEachNamedMember(probe, [&]<std::size_t I>(std::string_view name, const auto& member) {
1772 using Member = std::remove_cvref_t<decltype(member)>;
1773 if (!(isStdOptional<Member> || declaredOptional<Sub>(name))) {
1774 requiredNames.emplace_back(std::string{name});
1775 }
1776 auto& property = node["properties"][std::string{name}];
1777 property["x-order"] = std::uint64_t{I};
1778 annotateBasicMemberProperty<Sub, Member>(property, name);
1779 recurseIntoNestedAggregateIfAny<Member, Ancestors..., Sub>(dom, property);
1780 });
1781 // Idempotent if two members (or two actions sharing this schema call)
1782 // resolve to the same $defs entry: re-deriving the identical required
1783 // array is harmless.
1784 node["required"] = requiredNames;
1785}

1787/// @brief Resolves the object-schema DOM node for a nested-aggregate member,
1788/// given the property (or array `items`) node glaze wrote for it, and
1789/// annotates it via `annotateNestedAggregate<Sub, Ancestors...>`.
1790///
1791/// Handles both forms `Sub` can take in the schema (see
1792/// `annotateNestedAggregate`'s doc comment): a `$ref` into `$defs` (`Sub` used
1793/// 2+ times somewhere in the schema) resolves to that shared def; anything
1794/// else is assumed to be the inlined object schema itself (`Sub` used exactly
1795/// once). A property that is neither -- glaze emitted something other than an
1796/// object schema for a type this function's caller already confirmed is a
1797/// `ReflectableAggregate` -- is left untouched rather than guessed at.
1798/// @tparam Sub Nested aggregate type, as `annotateNestedAggregate` requires.
1799/// @tparam Ancestors The ancestor chain so far (excluding `Sub`), forwarded
1800/// to `annotateNestedAggregate` unchanged.
1801/// @param dom The whole schema DOM (so a `$ref`'s `$defs` entry can be found).
1802/// @param propertyOrItems The property node itself (single nested member) or its
1803/// array `items` node (`std::vector<Sub>` member).
1804template <typename Sub, typename... Ancestors>
1805void annotateNestedAggregateRef(glz::generic_u64& dom, glz::generic_u64& propertyOrItems) {
1806 constexpr std::string_view kDefsPrefix = "#/$defs/";
1807 if (propertyOrItems.contains("$ref")) {
1808 if (auto const* ref = propertyOrItems["$ref"].get_if<std::string>()) {
1809 if (std::string_view{*ref}.starts_with(kDefsPrefix)) {
1810 auto const key = std::string{ref->substr(kDefsPrefix.size())};
1811 // Checked, not indexed-and-hope: glz::generic_u64's object
1812 // storage reallocates on insert, so indexing a missing key
1813 // here would both fabricate a bogus empty $defs entry AND --
1814 // now that annotateNestedAggregate recurses -- risk dangling
1815 // a `node` reference an enclosing frame still holds into this
1816 // same $defs map. Well-formed glaze output never names a
1817 // $defs key that doesn't exist, so this only changes behavior
1818 // for malformed input, which is left untouched instead.
1819 if (dom.contains("$defs") && dom["$defs"].contains(key)) {
1820 annotateNestedAggregate<Sub, Ancestors...>(dom, dom["$defs"][key]);
1821 }
1822 }
1823 }
1824 return;
1825 }
1826 if (propertyOrItems.contains("properties")) {
1827 annotateNestedAggregate<Sub, Ancestors...>(dom, propertyOrItems);
1828 }
1829}

1831/// @brief The DOM post-merge behind `schemaJson`: adds the derived `required`
1832/// array, `x-order`, `x-decimalPlaces`, and (for actions declaring
1833/// `computedFields`) `x-computed`/`x-readonly` to a glaze-produced schema.
1834///
1835/// Separated from `schemaJson` so the fallback path (malformed input passes
1836/// through unchanged) is directly testable.
1837// NOLINTBEGIN(cppcoreguidelines-pro-bounds-avoid-unchecked-container-access) — glaze DOM requires operator[]
1838template <typename A>
1839[[nodiscard]] std::string mergeSchemaExtras(std::string rawSchema) {
1840 // u64 number mode: the schema carries int64/uint64 bounds in $defs, which
1841 // the default double-only DOM would silently round.
1842 glz::generic_u64 dom{};
1843 if (glz::read_json(dom, rawSchema)) {
1844 return rawSchema;
1845 }
1846
1847 glz::generic_u64::array_t requiredNames{};
1848 // Wire keys of every reflected member, in declaration order — reused
1849 // below to silently ignore a formLayout/fieldSpans entry that names a
1850 // field the action does not actually have (schema generation never
1851 // throws over an author's declaration mistake).
1852 std::vector<std::string_view> memberNames{};
1853 A probe{};
1854
1855 // Computed-field destination names -> their declared input wire names,
1856 // resolved once against the probe. Empty when A declares no
1857 // computedFields (the common case), so every lookup against it below is
1858 // then trivially false -- no schema change for actions that don't opt in.
1859 std::unordered_map<std::string_view, std::vector<std::string_view>> computedInputs{};
1860 if constexpr (HasComputedFields<A>) {
1861 std::apply([&](const auto&... field) { (collectComputedInputs(probe, field, computedInputs), ...); },
1862 A::computedFields.fields);
1863 }
1864
1865 forEachNamedMember(probe, [&]<std::size_t I>(std::string_view name, const auto& member) {
1866 using Member = std::remove_cvref_t<decltype(member)>;
1867 static_cast<void>(member);
1868 memberNames.push_back(name);
1869 const bool isComputed = computedInputs.contains(name);
1870 // A computed field is derived, not user-entered: exclude it from
1871 // `required` the same way an opted-out or std::optional field is.
1872 const bool isOptional = isStdOptional<Member> || declaredOptional<A>(name) || isComputed;
1873 if (!isOptional) {
1874 requiredNames.emplace_back(std::string{name});
1875 }
1876 auto& property = dom["properties"][std::string{name}];
1877 property["x-order"] = std::uint64_t{I};
1878 if (isComputed) {
1879 property["x-readonly"] = true;
1880 glz::generic_u64 computedMeta{};
1881 glz::generic_u64::array_t inputsList{};
1882 for (auto const& inputName : computedInputs.at(name)) {
1883 inputsList.emplace_back(std::string{inputName});
1884 }
1885 computedMeta["inputs"] = inputsList;
1886 property["x-computed"] = computedMeta;
1887 }
1888
1889 // Label/title/FieldMeta/Quantity/Choice/widget/ranged-bounds: shared
1890 // with the nested-aggregate recursion's per-member pass so both apply
1891 // identical rules (see annotateBasicMemberProperty's doc comment).
1892 annotateBasicMemberProperty<A, Member>(property, name);
1893
1894 // Nested aggregates (recursive, cycle-guarded -- docs/spec/forms/forms.md,
1895 // "Nested aggregates (recursive, cycle-guarded)"): a member whose type
1896 // is itself a reflectable aggregate gets an object schema from glaze --
1897 // either inlined directly into this property (the type is used exactly
1898 // once in the whole schema) or shared via `$defs`/`$ref` (used 2+
1899 // times). `recurseIntoNestedAggregateIfAny` resolves whichever form it
1900 // is and recurses so that object schema's own members get
1901 // `x-order`/`required`/title/Quantity/Choice/widget annotations too,
1902 // however deep the type graph goes (guarding against cycles at compile
1903 // time -- see that function's doc comment). Purely additive: an action
1904 // with no nested aggregate member has nothing here to trigger on, so
1905 // its schema is byte-for-byte unchanged.
1906 recurseIntoNestedAggregateIfAny<Member, A>(dom, property);
1907 });
1908 // Always assign — an explicit empty array beats leaving whatever the
1909 // schema writer may have emitted (or omitted) for `required`.
1910 dom["required"] = requiredNames;
1911
1912 // Layout & grouping (docs/spec/forms/forms.md, "Layout & grouping"):
1913 // purely additive over the required/x-order pass above; a no-op unless
1914 // the action declares a static constexpr `formLayout`.
1915 if constexpr (detail::HasFormLayout<A>) {
1916 glz::generic_u64::array_t groupsJson{};
1917 // wire key -> 0-based index into A::formLayout; a field claimed by
1918 // two groups keeps the first (declaration order wins, silently —
1919 // schema generation never throws over an author's declaration
1920 // mistake).
1921 std::vector<std::pair<std::string_view, std::size_t>> sectionOf{};
1922 std::size_t groupIndex = 0;
1923 for (auto const& group : A::formLayout) {
1924 glz::generic_u64::array_t fieldsJson{};
1925 for (std::string_view fieldName : group.fields) {
1926 bool const isMember =
1927 std::find(memberNames.begin(), memberNames.end(), fieldName) != memberNames.end();
1928 if (!isMember) {
1929 continue; // names a field the action does not have: ignored, never thrown
1930 }
1931 bool alreadyPlaced = false;
1932 for (auto const& placed : sectionOf) {
1933 if (placed.first == fieldName) {
1934 alreadyPlaced = true;
1935 break;
1936 }
1937 }
1938 if (alreadyPlaced) {
1939 continue; // first group to claim a field wins
1940 }
1941 fieldsJson.emplace_back(std::string{fieldName});
1942 sectionOf.emplace_back(fieldName, groupIndex);
1943 }
1944 glz::generic_u64 groupJson{};
1945 groupJson["title"] = std::string{group.title};
1946 groupJson["kind"] = std::string{groupKindName(group.kind)};
1947 groupJson["fields"] = fieldsJson;
1948 groupsJson.emplace_back(std::move(groupJson));
1949 ++groupIndex;
1950 }
1951 dom["x-layout"]["groups"] = groupsJson;
1952
1953 for (auto const& placed : sectionOf) {
1954 auto& property = dom["properties"][std::string{placed.first}];
1955 property["x-group"] = std::string{A::formLayout[placed.second].title};
1956 property["x-section"] = std::uint64_t{placed.second};
1957 }
1958 }
1959
1960 // Column spans (docs/spec/forms/forms.md, "Layout & grouping"): a no-op
1961 // unless the action declares a static constexpr `fieldSpans`.
1962 if constexpr (detail::HasFieldSpans<A>) {
1963 for (auto const& span : A::fieldSpans) {
1964 if (span.colspan <= 1) {
1965 continue; // 1 is the default width; nothing to advertise
1966 }
1967 bool const isMember = std::find(memberNames.begin(), memberNames.end(), span.field) != memberNames.end();
1968 if (!isMember) {
1969 continue; // names a field the action does not have: ignored, never thrown
1970 }
1971 auto& property = dom["properties"][std::string{span.field}];
1972 property["x-colspan"] = span.colspan;
1973 }
1974 }
1975
1976 // Cross-field rules (docs/spec/forms/forms.md's `x-rules`): emitted only
1977 // when the action declares `formRules`, so an unannotated action's
1978 // schema is byte-identical to before this feature existed. Walks
1979 // whatever rule node types A::formRules holds -- every node type past
1980 // and future exposes the same emitNode() -> glz::generic_u64 shape, so
1981 // this loop needs no changes as new rule kinds are added. (Named
1982 // emitNode(), not emit(), because Qt's <QObject> headers `#define emit`
1983 // as an empty macro -- a bare `emit()` silently vanishes and fails to
1984 // parse in any translation unit that includes both Qt and this header,
1985 // e.g. examples/forms/gui_qml/FormsController.cpp.)
1986 if constexpr (HasFormRules<A>) {
1987 glz::generic_u64::array_t xRules{};
1988 std::apply([&](const auto&... rule) { (xRules.emplace_back(rule.emitNode()), ...); }, A::formRules.rules);
1989 dom["x-rules"] = xRules;
1990 }
1991
1992 // value_or without a move: the copy is irrelevant (schemaJson memoises),
1993 // and keeping the fallback branch inside glaze's expected avoids an
1994 // untestable line here (write_json of a DOM we just built cannot fail).
1995 return glz::write_json(dom).value_or(rawSchema);
1996}

2094/// @brief Retags every `Quantity` member of @p action to its **declared**
2095/// precision, so a stored value matches the precision the schema
2096/// advertises via `x-decimalPlaces`.
2097///
2098/// A wire payload carries each `Quantity` with its own runtime `dp`, which a
2099/// client may set to anything. Left alone, the field is stored at the client's
2100/// `dp`, silently contradicting the schema's `x-decimalPlaces` (which is the
2101/// field's compile-time *declared* precision, `Quantity<U, Dec>::declaredDecimals`).
2102/// Calling this on the decode path — right after `ActionTraits<A>::fromJson` and
2103/// before dispatch — re-tags each `Quantity` to `declaredPrecision()` so the two
2104/// agree. `atDeclaredPrecision()` only changes the value's precision tag (an
2105/// exact `Rational` re-rounding to the declared decimals); an empty `Quantity`
2106/// is left empty. Non-`Quantity` members are untouched.
2107///
2108/// This is the enforcement half of the `x-decimalPlaces` contract: the schema
2109/// advertises the declared precision and the dispatch path now stores at that
2110/// precision, rather than honouring whatever `dp` the client sent.
2111/// @tparam A Action type (a reflectable aggregate).
2112/// @param action Draft action whose `Quantity` members are retagged in place.
2113template <typename A>
2114constexpr void reconcileDeclaredPrecision(A& action) {
2115 using Plain = std::remove_cvref_t<A>;
2116 // Only actions glaze can reflect member-by-member (aggregates, or types with
2117 // a `glz::meta`) can be walked here. Actions with hand-written codecs and no
2118 // reflectable shape — and there is nothing to retag on them anyway — fall
2119 // through as a no-op so this stays safe to call for *every* registered

Detailed Description

The QML components a client renders beside the built-in kinds (spec 5 §10).

  • A host component is QML the client carries, registered by name and version. It loads into the backend's own engine, so it may import the application's other modules.
  • A bundle component is QML text delivered in the application's bundle and named by its SHA-256 digest. It loads only when the text matches the digest, and compiles in a dedicated engine whose root context holds nothing, so it sees nothing but what is set on it.
  • The restyle map names a component for a built-in kind. The component must declare every property and function of the kind's MorphUi component; one that does not is refused when it is mapped.

Each component reports its events through host.fire(event, payload), host being a var property it declares and the renderer sets. A component that fails to load is reported once, through the callback, and the caller renders its fallback. Neither copyable nor movable; it outlives every backend that uses it.

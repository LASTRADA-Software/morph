Detailed Description

The expr/1 expression language of the UI document: parsing a JSON expression into an Expr tree, checking it against the names a document declares, and evaluating it.

Specified in docs/spec/ui/expressions.md.

The forms of an expr/1 expression (spec 5 §4).

Enumerator
Literal 

A JSON scalar, or {"lit": v}.

Ref 

{"ref": "name.path"}.

Row 

{"row": "path"}.

Query 

{"query": "q"}: a query's value.

Pending 

{"pending": "q"}: whether a query or mutation is in flight.

Error 

{"error": "q"}: a query's or mutation's error text.

Result 

{"result": "m"}: a mutation's last result.

ErrorKind 

{"errorKind": "m"}: the kind of a query's or mutation's error.

Can 

{"can": "m"}: whether the principal may run a mutation or query.

Pref 

{"pref": "point.path"}: the user's choice at a customization point.

Call 

{"fn": "name", "args": [...]}, and {"t": ...}.

If 

{"if": [cond, then, else]}.

Object 

{"obj": {...}}.

List 

{"list": [...]}.

Map 

{"map": e, "as": "x", "to": e}.

Filter 

{"filter": e, "as": "x", "where": e}.

Env 

{"env": "name"}: the client environment.

Session 

{"session": "name"}: a session attribute.

Host 

{"host": "name"}: a value the application registered with the client.

◆ checkExpression()

std::expected< Type, Refusal > morph::ui::checkExpression ( Expr const & expr,
NameResolver const & resolver )
inlinenodiscard

Checks an expression against the names a document declares.

Every reference is resolved through resolver, comprehension variables first; the arguments of a function, the condition of if and the where of filter are checked against their accepted kinds where the argument's type is statically known; a literal t fallback must be in the ui/1 message subset.

Parameters
exprThe expression.
resolverWhat the document's names resolve to.
Returns
The expression's static type (any where it cannot be known), or the refusal.

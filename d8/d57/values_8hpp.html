Detailed Description

Specified in docs/spec/forms/engine.md, "Values and exactness".

◆ encodeScalar()

Encoding morph::forms::encodeScalar ( FieldSpec const & spec,
std::string_view draft,
std::size_t unit,
ValueContext const & context )
inlinenodiscard

Encodes one scalar field's draft (every kind but Object and ObjectArray).

The draft is trimmed first. Blank is std::nullopt — except a required Boolean, which encodes false: an unchecked box is an answer, and a required box always shows one.

Parameters
specThe field.
draftWhat the user typed, or what a control holds (an option's valueJson, true/false).
unitFor a Decimal or Quantity, the index into spec.units the draft is typed in.
contextThe locale, display zone and translations.
Returns
The encoding.

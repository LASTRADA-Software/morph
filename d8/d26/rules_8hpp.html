inlinenodiscard

Whether the gating rules let the form submit.

Only a False rule blocks: an Unknown one is waiting on a field that is required or does not encode, and that field blocks readiness itself; and a rule kind this engine does not know must not lock an older client out of a newer server's forms.

Parameters
rulesThe rules.
lookupReads each operand.
Returns
False when some gating rule is false, Unknown when none is false and some is undecided, else True.

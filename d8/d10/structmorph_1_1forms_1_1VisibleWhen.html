Detailed Description

template<typename V, typename A, typename Cond>
struct morph::forms::VisibleWhen< V, A, Cond >

Presentation rule: the listed field is shown only while Cond holds. Never gates allRulesSatisfied — while hidden, the field's current draft value still travels in the payload (hiding never clears it), exactly like a static x-hidden field.

Reads a chat's configuration from JSON text.

A key the format does not have is refused, so a misspelled limit cannot silently leave the default in force. What is left out keeps its default. The key comes from apiKeyEnv, the name of an environment variable, or from an inline apiKey; naming both is refused. A refusal says what is wrong without quoting the text, which may hold the key.

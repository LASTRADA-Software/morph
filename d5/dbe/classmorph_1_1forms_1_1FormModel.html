Detailed Description

The immutable runtime model of one action's form.

Built from schema JSON by fromSchema; forAction<A>() (which the typed facade Form<A> uses) reads schemaJson<A>() through the same reader, so a typed and a runtime form of one action are the same model.

std::string_view schemaJson,
FieldOverlays const & overlays = {} )
inlinestaticnodiscard

Reads a schema document, with the overlays a document or an application states for its fields.

omit, hidden, label, widget and blankAs are applied to the schema before it is read, so a widget overlay chooses the kind exactly as the schema's own x-widget would; unit and decimals are applied to the read field. An overlay naming a field the schema does not have is a SchemaError, as is a unit that is not one of a Quantity's units.

Parameters

Returns
The model, or the error naming where the document is malformed.

template<class A>
FormModel morph::forms::FormModel::forAction ( )
staticnodiscard

The model of a registered action's own form: fromSchema over ActionTraits<A>::typeId() and schemaJson<A>().

Declared here and defined in forms/engine/typed_form.hpp, the one engine header that includes the schema emitters; include that header to call it. The schema is compiled from A, so a reader error is a defect in the emitter or the engine, never bad input: it throws rather than returning an expected every caller would have to unwrap.

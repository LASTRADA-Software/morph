◆ pluralCategory()

PluralCategory morph::ui::pluralCategory ( std::string_view locale,
math::Rational const & value,
std::uint32_t places )
inlinenodiscard

The CLDR plural category of a number in a locale.

The operands are CLDR's: n the absolute value, i its integer digits, v the count of visible fraction digits (the decimal's places; an int has none). Rules are carried for en, de, nl, sv, it, es, pt, fr, pl, ru, uk, cs and ar; ja, zh, ko and every other language select only other. The locale's language subtag decides, case-insensitively, so pl-PL uses the Polish rules.

Parameters
localeA BCP 47 locale, such as pl-PL.
valueThe exact number.
placesThe visible fraction digits.
Returns
The category.

◆ parseMessage()

std::expected< MessagePattern, std::string > morph::ui::parseMessage ( std::string_view text)
inlinenodiscard

Parses a message in the ui/1 subset of MessageFormat 2.

The subset is: text with \\endiskip escapes; placeholders {$name}, {$name :number} and {$name :string}; .input declarations of the same form; and .match over declared :number or :string variables, with variant keys that are plural categories, exact numbers (0, =0), exact strings, or *, and a required catch-all. Literal placeholders, options, markup and .local are outside it.

Parameters
textThe message source.
Returns
The parsed message, or the reason it is refused.

Mounts the client's shell for what source delivered.

On a bundle: loads each screen of source.screens() with the source's catalog facts, opens the start screen as a tab, and on a document's navigate or a navigator choice opens the screen asked for as a tab (or focuses the tab that shows it), from a task posted to the owner, never from inside the handler that asked. A sign-in or sign-out closes every tab and rebuilds the frame for the new catalog. On a ConnectError, or when no screen can be mounted, shows why as text.

Parameters
contextThe frontend's context.
backendThe view backend the screens mount on. Borrowed: it outlives the shell.
openedWhat the source delivered.
sourceThe source; it outlives the shell.
optionsThe start screen and the observers.
Returns
The shell; destroying it unmounts everything.
Exceptions
std::invalid_argumentwhen options.signIn is empty.

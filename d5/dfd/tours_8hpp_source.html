154/// @brief Runs at most one of the app's tours: opens each step's screen, prepares a shell target, points the
155/// spotlight at the step's target, and moves on with Next, Back, a waiting step's screen, or End.
156///
157/// A shell makes one with each frame and destroys it with the frame, which ends a running tour. It reads the tours
158/// from `AppRoot::tours()`, runtime tours included, and follows them while a tour runs, so a change of locale
159/// re-evaluates the card's texts. Neither copyable nor movable; on the runtime's owner.
160class MORPH_API TourController {
161public:
162 /// @brief A controller with no tour running.
163 /// @param runtime The runtime the root's values belong to. Borrowed.
164 /// @param root The app document's root. Borrowed: it outlives the controller.
165 /// @param shell The shell the tours run in. Borrowed: it outlives the controller.
166 /// @param options Where warnings and changes go.
167 TourController(reactive::Runtime& runtime MORPH_LIFETIMEBOUND, AppRoot const& root MORPH_LIFETIMEBOUND,
168 TourShell& shell MORPH_LIFETIMEBOUND, TourControllerOptions options = {});
169
170 /// @brief Stops following the tours. The spotlight is left to the frame, which goes with the controller.
171 ~TourController();
172
173 TourController(TourController const&) = delete;
174 TourController& operator=(TourController const&) = delete;
175 TourController(TourController&&) = delete;
176 TourController& operator=(TourController&&) = delete;
177
178 /// @brief Ends a running tour, opens the tour's screen when it names one the active tab does not show, opens the
179 /// spotlight and shows the first step. A screen that cannot be opened ends the tour with a toast.
180 /// @param tourId The tour.
181 /// @return Nothing, or the refusal of an id the app offers no tour for, which starts nothing.
182 std::expected<void, Refusal> start(std::string_view tourId);

184 /// @brief Shows the next step, or ends the tour on the last one. A step that waits for a screen ignores it.

195 void activeChanged();
196
197 /// @brief Tells the controller the frame went between its wide and compact forms: the running step's target is
198 /// rung again in the new form, a navigator entry as itself or as the navigation menu. Nothing opens or

200 void formChanged();
201
202 /// @brief Whether a tour runs.
203 /// @return It.
204 [[nodiscard]] bool running() const noexcept { return !_tourId.empty(); }
205
206 /// @brief Whether the app offers a tour.
207 /// @param tourId The tour.

211 /// @brief What the card shows of the running step.

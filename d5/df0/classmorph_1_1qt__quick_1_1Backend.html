Detailed Description

ui::IViewBackend over Qt Quick: each widget is a Qt Quick item made from its kind's MorphUi component, or from the component the restyle map names for that kind.

Every root a mount makes is appended to a column the backend adds to the host item, so several roots share it top to bottom. Neither copyable nor movable. It belongs to the thread of its engine, and every widget it makes is destroyed before it.

CustomRequest const & request )

Loads a custom component by name.

A host component loads into this backend's engine; a bundle component must match its digest and compiles in the components' contained engine. A component that cannot be loaded — not registered, a host component below minVersion, a digest that does not match, a compile error, a declared prop it lacks — is reported once through the components' failure callback, and the caller shows the fallback.

Parameters

requestThe component and the props the document declares.
Returns

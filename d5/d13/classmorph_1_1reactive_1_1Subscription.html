Detailed Description

template<typename R>
class morph::reactive::Subscription< R >

The latest R the bridge published on a handler's instance, as reactive state.

Uses the handler's one subscription slot for R: two consumers of the same R use two handlers. The subscription is gated by a scope the Subscription owns, so a publish delivered after it is destroyed — one already queued included — is dropped. The handler keeps the dead entry until it is destroyed or subscribes to R again. A delivery off the Runtime's owner is reported (detail::site::kOffOwner) and dropped.

latest() is state, not an event stream: when R compares with ==, a publish equal to the current value does not notify. For something to happen on every publish, use Query::refreshOn.

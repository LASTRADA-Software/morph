Detailed Description

A UTC instant with millisecond precision.

The default state is the Unix epoch — DateTime itself has no empty state; use Timestamp for fields that may be blank.

◆ fromIso8601()

static std::optional< DateTime > morph::time::DateTime::fromIso8601 ( std::string_view  text)
inlinestaticnoexcept

Strictly parses ISO-8601 UTC: YYYY-MM-DDTHH:MM:SS, optionally followed by .m/.mm/.mmm and an optional trailing Z.

The calendar date must exist (2026-02-30 is rejected) and clock components must be in range; no time zones other than Z, no lowercase separators, no trailing input. The fixed-width date and clock fields (month, day, hour, minute, second, fraction) reject a leading sign; only the year field may carry a - (negative years).

Parameters
textCandidate ISO-8601 string.
Returns
The parsed instant, or std::nullopt when text is malformed.

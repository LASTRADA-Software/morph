template<auto U, std::uint32_t DeclaredDecimals>
bool morph::units::Quantity< U, DeclaredDecimals >::withinDeclaredBounds ( ) const
inlinenodiscardconstexprnoexcept

Pre-decode validation seam: whether the current payload falls within this field's unit-declared bounds (UnitTraits<E>::bounds), when the unit declares any. An empty payload, or a unit with no declared bounds() (HasUnitBounds not satisfied), is always within bounds — this is an opt-in check, not a new default restriction, so a unit system that declares no bounds behaves exactly as it did before this feature existed.

Comparison is on the exact Rational value only (never a lossy double), consistent with every other exact comparison in this header.

Returns
true when empty, when the unit declares no bounds, or when the engaged value satisfies min <= value <= max.

◆ roundedToDecimalPlaces()

template<auto U, std::uint32_t DeclaredDecimals>
Quantity morph::units::Quantity< U, DeclaredDecimals >::roundedToDecimalPlaces ( math::DecimalPlaces newPrecision,
math::RoundingMode mode = math::RoundingMode::HalfAwayFromZero ) const
inlinenodiscard

Rounds the value to a runtime precision, changing the exact value as well as the tag — unlike withDecimalPlaces, which retags only and leaves display and storage free to disagree.

Delegates to math::roundToDecimalPlaces, and so shares its saturation behaviour: a value whose scaled form leaves int64 range clamps and logs instead of overflowing. A value already representable at newPrecision is unchanged apart from its tag.

Parameters
newPrecisionRuntime precision; silently clamped to the valid range.
modeTie-breaking rule; defaults to half away from zero, matching the decimal display path.
Returns
The rounded quantity, or empty if this is empty.

template<auto U, std::uint32_t DeclaredDecimals>
Quantity morph::units::Quantity< U, DeclaredDecimals >::atDeclaredPrecision ( ) const
inlinenodiscard

Rounds the value to this field's declared precision — the one the generated schema advertises as x-decimalPlaces.

The enforcement half of the x-decimalPlaces contract: the stored value becomes the value that renders at the declared precision, so a handler never persists digits the form does not show. Rounds half away from zero, the rule the decimal formatter uses.

Returns
The rounded quantity, or empty if this is empty.

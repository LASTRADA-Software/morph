◆ ButtonEmphasis

enum class morph::ui::ButtonEmphasis : std::uint8_t
strong

How much a button stands out; each backend maps it to its theme.

Enumerator
Normal 

An ordinary action.

Primary 

The screen's main action.

Danger 

An action that destroys or cannot be undone.

Ghost 

An action embedded in other content, with no chrome of its own.

DangerOutline 

A destructive action that is not the main one: outlined, its label in the error colour, so the screen's filled action stays the one that stands out.

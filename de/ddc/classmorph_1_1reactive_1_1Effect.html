Detailed Description

A side effect: runs once on construction, then in a flush after any source it read changed.

Queued Effects run shallowest scope first: an Effect a Scope makes carries that scope's depth, so an owner's Effects run before those of the scopes it owns. Among Effects of one depth, older ones run first.

An exception escaping it is a defect: reported (detail::site::kEffectThrew), and the flush stops. A run that throws keeps every source it has read, before and during that run, so a later change to any of them runs it again. A body may destroy its own Effect (a remount); the body's callable stays alive until the body returns, and the Effect is not touched afterwards.

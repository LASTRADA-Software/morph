Detailed Description

One document scope at run time: the screen, a dialog's or drawer's content, a switch case or a row.

It lives while anything that reads it does: the view nodes lowered in it hold it by shared_ptr, a reply or a timer holds it weakly. It belongs to a ScreenCore, which outlives it.

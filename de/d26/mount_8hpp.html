◆ stableTargets()

std::vector< bool > morph::ui::detail::stableTargets ( std::vector< std::size_t > const & sequence)
inlinenodiscard

Which entries of a permutation lie on one longest increasing run.

sequence holds, in current order, each widget's target position; the widgets on the run are already in order relative to each other and stay where they are, and every other one is moved once.

Parameters
sequenceA permutation of 0 .. n-1.
Returns
Indexed by target position: whether that widget stays.

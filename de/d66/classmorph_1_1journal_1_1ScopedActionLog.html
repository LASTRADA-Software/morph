Detailed Description

RAII helper that installs a default action log for its lifetime and restores the previous one on destruction.

Mirrors morph::log::ScopedLoggerOverride. Intended for tests (so one test case's sink never leaks into the next) and for applications that need to temporarily redirect auto-attached logging within a scope.

Example
{
morph::journal::ScopedActionLog guard{std::make_shared<morph::journal::InMemoryActionLog>()};
// ... models created in this scope auto-attach guard's log ...
} // previous default restored here

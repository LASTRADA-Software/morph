Detailed Description

Opt-in, connection-agnostic resource limits enforced by RemoteServer.

Every field defaults to 0, meaning "unbounded" — installing no policy (or installing a default-constructed one) reproduces today's behavior exactly. Install via RemoteServer::setLimitPolicy(). See docs/spec/core/backend.md.

std::chrono::milliseconds morph::backend::LimitPolicy::executeTimeout {0}

Max wall-clock time a single execute may take before the server sends an err "timeout" reply and discards the eventual strand result. 0 = no timeout (today's behavior).

The model action itself is never interrupted — it keeps running to completion on its strand. This bounds the caller's wait, not the model.

Detailed Description

Owns one scheduled timer and cancels it when destroyed. Move-only.

A scheduler hands it two functions: one that cancels the timer and one that says whether the timer is still scheduled. So active() turns false once a one-shot timer has fired, and cancelling a fired timer does nothing.

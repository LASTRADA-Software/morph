Detailed Description

The headless controller of custom screens over one workspace: per-tab drafts, the commands that save, discard, open and remove them, and their outcomes as data, for any view to draw.

Specified in docs/spec/ui/custom_screens.md, "The client".

enum class morph::ui::CustomScreenEvent : std::uint8_t
strong

What happened, for the person to be told.

Enumerator
Saved 

The save completed and the tab shows the saved screen.

SavedTabClosed 

The save completed, but its tab was closed first.

SavedDraftReplaced 

The save completed, but the tab now holds another draft, which is not saved.

SavedDraftGone 

The save completed, but the draft it was saved from is gone.

SavedNotOpened 

Save as completed, but the saved screen could not be opened; detail says why.

SavedNotReread 

Save completed, but the stored screen could not be read again; detail says why.

SavedStaysDraft 

Save as completed, but the screen stayed open, so the tab stays a draft; detail says why, empty when the person kept it open.

SaveRefused 

A save whose asker is gone was refused; detail is the refusal.

Removed 

The screen was removed.

RemovedStaysOpen 

The screen was removed, but a tab showing it stayed open; detail says why, empty when the person kept it open.

OpenAsCancelled 

Open as was cancelled: the screen stayed open. title is that screen's.

OpenFailed 

A screen could not be opened; detail says why.

SourceUnreadable 

A tab's source could not be read; detail says why, and may be empty.

StoredSourceUnreadable 

A stored custom screen's source could not be read; detail says why.

ProposalNotShown 

The assistant's draft could not be mounted; detail says why.

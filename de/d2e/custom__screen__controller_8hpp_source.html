35/// @brief What happened, for the person to be told.
36enum class CustomScreenEvent : std::uint8_t {
37 Saved, ///< The save completed and the tab shows the saved screen.
38 SavedTabClosed, ///< The save completed, but its tab was closed first.
39 SavedDraftReplaced, ///< The save completed, but the tab now holds another draft, which is not saved.
40 SavedDraftGone, ///< The save completed, but the draft it was saved from is gone.
41 SavedNotOpened, ///< **Save as** completed, but the saved screen could not be opened; `detail` says why.
42 SavedNotReread, ///< **Save** completed, but the stored screen could not be read again; `detail` says why.
43 SavedStaysDraft, ///< **Save as** completed, but the screen stayed open, so the tab stays a draft; `detail`
44 ///< says why, empty when the person kept it open.
45 SaveRefused, ///< A save whose asker is gone was refused; `detail` is the refusal.
46 Removed, ///< The screen was removed.
47 RemovedStaysOpen, ///< The screen was removed, but a tab showing it stayed open; `detail` says why, empty when
48 ///< the person kept it open.
49 OpenAsCancelled, ///< **Open as** was cancelled: the screen stayed open. `title` is that screen's.
50 OpenFailed, ///< A screen could not be opened; `detail` says why.
51 SourceUnreadable, ///< A tab's source could not be read; `detail` says why, and may be empty.
52 StoredSourceUnreadable, ///< A stored custom screen's source could not be read; `detail` says why.
53 ProposalNotShown, ///< The assistant's draft could not be mounted; `detail` says why.
54};

56/// @brief Which save an outcome is about.
57enum class CustomScreenSaveKind : std::uint8_t {
58 None, ///< Not a save.
59 Save, ///< **Save**: an overwrite of the person's own screen.
60 SaveAs, ///< **Save as**: a new screen.
61};

92/// @brief How a check asked from a source view ended.
93enum class CustomScreenCheckStatus : std::uint8_t {
94 Done, ///< It passed, and what it was asked for was done: the draft mounted, or the screen saved.
95 Refused, ///< The client, the server, the store or the host refused; `refusal` says where and why.
96 Dropped, ///< Its answer came after `dropSourceAnswers`, or after the tab's draft changed, so nothing was done.
97};

99/// @brief What a check asked from a source view answers.
100struct CustomScreenCheckResult {

103 /// @brief The refusal, for `Refused`: a JSON Pointer into the text checked, empty for the whole document.

152/// @brief The headless controller of custom screens over one workspace: what each tab holds and the commands over it,
153/// with no view of its own.
154///
155/// It keeps, per tab, the draft's text, a generation that changes with every draft mounted or ended, whether a save is
156/// in flight and the last refusal of a save. Its commands mount a checked edit as a tab's draft, save it as a new
157/// screen or over the person's own, discard it, open a screen in a tab's place, and remove a screen; an answer acts
158/// only on the draft it was asked about, and one that finds the tab holding another draft, or none, or closed, leaves
159/// the tab as it is and is told as an outcome. Outcomes and refusals are data (`CustomScreenOutcome`,
160/// `CustomScreenCheckResult`): wording them, in whatever language, is the view's. Its state is reactive, so a view's
161/// bindings follow it. Everything runs on the runtime's owner. Neither copyable nor movable.

366 // Wraps @p fn so it does nothing once the controller is gone, or under another workspace: answers arrive through
367 // the sync, which may outlive it, and tab ids are issued per workspace.
368 template <typename F>
369 [[nodiscard]] auto guarded(F fn) const {
370 return
371 [this, epoch = _epoch, alive = std::weak_ptr<bool>{_alive}, fn = std::move(fn)](auto&&... args) mutable {
372 if (auto const live = alive.lock(); live != nullptr && *live && _epoch == epoch) {
373 fn(std::forward<decltype(args)>(args)...);
374 }
375 };
376 }

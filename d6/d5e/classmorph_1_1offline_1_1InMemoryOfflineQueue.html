Detailed Description

Thread-safe in-memory implementation of IOfflineQueue.

Suitable for testing and for applications that do not require persistence across process restarts. Items are stored in a std::deque protected by a mutex.

inlineoverridevirtual

Updates the persisted attempt count on the in-deque item with itemId. No-op if itemId is not found. Thread-safe.

InMemoryOfflineQueue does not itself survive a process restart, but overriding this hook lets a fresh SyncWorker constructed over the same instance observe a durable-style cumulative attempt count — used to simulate cross-restart dead-lettering in tests.

Parameters

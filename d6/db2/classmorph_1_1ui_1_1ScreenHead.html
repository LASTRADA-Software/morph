Detailed Description

A screen's head beside its title: the eyebrow, the title's runs, the subtitle, the status badges, the tools, the actions and the head's own menu a shell shows above the screen (the document's eyebrow, titleSpans, subtitle, status, tools, actions and menu).

The head is data: the screen evaluates it and the shell draws it, so a host screen's handle can implement it too. The menu and tool members have defaults, for a head that has neither.

Detailed Description

Records a dictated clip from an audio input, by default the system's, converted to 16 kHz mono 16-bit as it arrives (SpeechResampler) and stopped at the server's bounds (DictationClip). Asks for microphone permission where the platform has it. Audio stays in memory and is never written to disk.

Lives on a thread running a Qt event loop, where it is made; its callbacks run there. Neither copyable nor movable.

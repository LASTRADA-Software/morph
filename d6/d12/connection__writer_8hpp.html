Detailed Description

What a transport hands RemoteServer to write to one connection, and the backlog bounds both sides apply.

Kept apart from remote.hpp so a transport's connection code, which both the client and the server role share, can use the bounds without compiling the server.

◆ ConnectionId

using morph::backend::ConnectionId = std::uint64_t

Opaque id a transport uses to scope model registrations to one connection so RemoteServer::closeConnection can reclaim them.

0 is reserved and means unscoped: it is what the two-argument RemoteServer::handle()/handleInline() overloads pass. Non-zero values are minted by RemoteServer::openConnection().

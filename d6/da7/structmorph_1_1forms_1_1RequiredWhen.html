Detailed Description

template<typename V, typename A, typename Cond>
struct morph::forms::RequiredWhen< V, A, Cond >

Rule: field must be engaged whenever Cond holds; vacuously satisfied (not required) while the condition does not hold.

Template Parameters
VField member type (must satisfy EngageableField).
AAction type the field belongs to.
CondCondition node type (e.g. Engaged<V2, A>).

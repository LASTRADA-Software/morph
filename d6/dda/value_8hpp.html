◆ valueFromJson() [1/2]

std::expected< Value, std::string > morph::ui::valueFromJson ( Json const & json)
inlinenodiscard

Reads a value from its JSON form, structurally.

null, booleans, integers, strings, arrays and objects map to their kinds. An object of exactly num, den and dp is a decimal, and with unit a quantity: the wire form of math::Rational. A number with a fraction or an exponent is refused, because an exact value is never written as a double; an integer beyond int64 is refused. A timestamp has no structural form — it is a string — so it is read through the typed overload.

Parameters
jsonThe JSON value.
Returns
The value, or the reason it is refused.

Variable Documentation

◆ kMaxJsonDepth

std::size_t morph::ui::kMaxJsonDepth = 64
inlineconstexpr

The deepest a document's JSON may nest, counting each object and array as one level.

Documents written by hand or by the builders nest a dozen levels or so. The bound is checked before the JSON parser runs, because the parser and every later pass over the tree descend recursively, and a hostile document nested a few hundred levels deep overflows a 1 MB thread stack before anything else can refuse it.

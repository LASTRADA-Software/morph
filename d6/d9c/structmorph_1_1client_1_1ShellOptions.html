◆ dev

bool morph::client::ShellOptions::dev = false

Development mode (spec 5 §12): every second the shell polls the source's ui-hello digest, and when it changed, remounts every open tab whose document changed, keeping its state. A shell built without the development tools never polls. A production client leaves it off: the digest is then read once.

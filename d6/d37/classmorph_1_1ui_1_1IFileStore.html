Detailed Description

Where uploaded and issued files live. Every call names the principal it is made for, and an upload id or a file reference works only for the principal it was made for.

A reference is a capability: whoever presents it, as the principal it belongs to, may read the file. It is therefore unguessable (newFileRef), and a store answers a reference of another principal exactly as one that does not exist.

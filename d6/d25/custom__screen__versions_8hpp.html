◆ layoutChanges()

MORPH_API std::expected< LayoutChanges, Refusal > morph::ui::layoutChanges ( std::string_view base,
ActionSchemaLookup const & baseSchemas,
std::string_view layout )
nodiscard

What changed in base since the version layout knows.

Added: each element of the base with a since above the copy's knownVersion whose id the copy does not have, with its place (an element inside another added element comes with it and is not listed), and each field of a base form's action with an x-since above it, for a form the copy has (the same id, or for a form without one the first form of the same action) and gives no overlay for that field. Removed: each element of the copy with a since whose id the base no longer has (an element a person adds has none), and each field overlay of a copy's form naming a field its action no longer has.

Parameters
baseThe base screen's JSON text.
baseSchemasThe action schemas; a form whose action it does not know is not compared.
layoutThe person's copy's JSON text.
Returns
The changes, or the refusal: a document that does not load, or a schema whose x-since is not a version.

◆ applyLayoutChoices()

MORPH_API std::expected< std::string, Refusal > morph::ui::applyLayoutChoices ( std::string_view base,
ActionSchemaLookup const & baseSchemas,
std::string_view layout,
LayoutChoices const & choices )
nodiscard

The person's copy updated by their choices, recording the base's version as knownVersion.

Each removal chosen Drop is removed from the copy; each field addition left out gets "omit": true in its form's fields; then each element addition taken over is inserted at its place: into the copy's element of the same id as its parent (the document itself for none), in the same member, at the base's index or at the end when the member is shorter. The result is loaded as a save loads it, so what comes back is a document; the server's checks still decide when it is saved.

Parameters
baseThe base screen's JSON text.
baseSchemasThe action schemas, as layoutChanges takes them.
layoutThe person's copy's JSON text.
choicesThe person's choices.
Returns
The updated copy, or the refusal: one layoutChanges gives, a choice for a key that names no change, an element whose place the copy does not have, or a result that does not load.

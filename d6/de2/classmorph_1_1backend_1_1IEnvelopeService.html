Detailed Description

Envelope kinds a RemoteServer answers through an extension, such as the UI service's ui-* kinds.

Core does not know the kinds a higher layer adds, and must not include that layer. A server consults its services only for a kind it does not answer itself, so a service cannot take over execute, hello or any other built-in kind; a kind no service serves is still answered err "unknown envelope kind: <kind>". See docs/spec/core/backend.md, "Envelope services".

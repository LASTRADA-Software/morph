Submitter morph::forms::handlerSubmitter ( exec::IExecutor & callbacks,
Handlers &... handlers )
nodiscard

A Submitter that sends each action through the first of handlers whose model registers it.

Use it when a form's submissions must reach the model instance the rest of the screen uses — an in-memory model, or a shared instance another handler attached. bridgeSubmitter keeps handlers of its own instead.

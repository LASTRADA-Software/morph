Detailed Description

What started an execute, as the server says.

Deliberately not part of Context: a Context arrives in the envelope, so a client can send anything in it. A RunOrigin is passed by server-side code through RemoteServer::executeWithOrigin, has no wire form, and is read through currentOrigin().

Detailed Description

template<auto Min, auto Max, auto Step = 1>
requires (std::is_arithmetic_v<decltype(Min)> && std::same_as<decltype(Min), decltype(Max)> && std::same_as<decltype(Min), decltype(Step)>)
struct morph::forms::Ranged< Min, Max, Step >

A bounded numeric field edited as a slider.

Template Parameters
MinInclusive lower bound of the control track.
MaxInclusive upper bound of the control track (must be > Min).
StepTrack increment (default 1; must be > 0). Must be the same arithmetic type as Min/Max — a floating-point Ranged must name Step explicitly (the default 1 is int).

Detailed Description

Configuration for NetworkMonitor.

Declared outside NetworkMonitor so that its default member initialisers are fully parsed before any constructor default argument that names Config{} is evaluated. Compilers (clang, GCC) reject Config cfg = Config{} in a constructor default argument when Config is an incomplete nested type.

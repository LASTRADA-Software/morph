Detailed Description

Date patterns: the one form in which an application shows and reads dates, such as dd-MMM-yyyy HH:mm. The expression formatter, the interpreter and both frontends call these, so the grammar lives in one place. Specified in docs/spec/ui/expressions.md.

◆ checkDatePattern()

std::expected< void, std::string > morph::ui::checkDatePattern ( std::string_view pattern,
bool withTime )
inlinenodiscard

Checks a date pattern: only the tokens yyyy, MM, MMM, dd, HH, mm, ss and xxx and the literals -, /, ., :, , and a space; yyyy, dd and one of MM or MMM once each; for a date and time also HH and mm once each and ss and xxx cursor most once, and for a date no time token; and no two tokens touching without a literal between them, except MMM beside a number. So every text it writes reads back to the same instant.

Parameters
patternThe pattern, such as dd-MMM-yyyy HH:mm.
withTimeWhether it is a date-and-time pattern rather than a date pattern.
Returns
Nothing, or why the pattern is refused.

Detailed Description

RAII helper that fixes DateTime::now() to a constant instant (or a custom callable) for its lifetime and restores the previous override on destruction.

Mirrors morph::journal::ScopedActionLog and morph::log::ScopedLoggerOverride — the same scoped-install-then-restore pattern used for the codebase's other process-wide override seams, so one test's fixed "now" never leaks into the next.

{
morph::time::ScopedNowOverride guard{someFixedInstant};
// ... DateTime::now()/Timestamp::now(), anywhere, return someFixedInstant ...
} // previous override (or real wall-clock time) restored here

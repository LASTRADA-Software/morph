Detailed Description

template<typename T>
class morph::ui::author::ResultHandle< T >

A mutation's result: a Handle with no field reads.

A result is not a named read, so a field of it cannot be read in place: the screen binds it first, auto r = screen.let("r", m.result());, and reads r.at(...). The at overloads are deleted, so the mistake is a compile error at the call rather than a refusal when the screen is registered. It converts to Handle<T> wherever a handle is taken.

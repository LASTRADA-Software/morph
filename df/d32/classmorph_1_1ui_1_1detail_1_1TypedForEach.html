Detailed Description

template<typename RowT>
class morph::ui::detail::TypedForEach< RowT >

The typed model behind forEach<RowT> and table<RowT>.

Template Parameters
RowTThe row type; copyable. With an operator==, an unchanged row notifies nobody; without one, every new snapshot notifies every kept row.

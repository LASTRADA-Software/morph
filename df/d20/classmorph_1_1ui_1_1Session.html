Detailed Description

What screens of one client session share (spec 5 §5, §12b): the query cache, the mounted queries, the principal's permitted actions, the formatting facts and the client's env, session and host values.

It belongs to the runtime's owner, outlives every screen mounted on it, and is cleared by signOut and on a principal change.

◆ actionSucceeded()

void morph::ui::Session::actionSucceeded ( std::string const & typeId,
std::string const & actionId,
Value const & reply,
ReplyUse use,
std::string const & instanceToken )
inline

A call of actionId on a model of typeId succeeded: applies the action's effects to the cache (spec 8 §9).

updates R merges the reply's rows of R into each entry holding R, matched by the record's key field at the entry's paths, with no fetch; an entry whose fetch is in flight also fetches once more, since that fetch may have read before the write. changes R marks each entry holding R stale. changesInstance marks each entry read through the same instance. A marked entry refetches through a mounted query that uses it. A discarded reply only marks: its updates act as changes.

Parameters
typeIdThe model type.
actionIdThe action.
replyThe reply's value.
useWhether the reply was applied or discarded.
instanceTokenThe instance token of the alias the call went through.

◆ deliverEvent()

void morph::ui::Session::deliverEvent ( wire::EventBody const & event)
inline

Applies a server event to the cache (spec 8 §9).

A changes event marks the entries it names stale, and a resync sends the whole watch set again, as reconnected does, and marks every entry but an evaluate one; each marked entry refetches through a mounted query that uses it, and one no query uses refetches when a query mounts on it. An event of another topic, or a payload that cannot be read, is ignored.

◆ applyChanges()

void morph::ui::Session::applyChanges ( wire::ChangesBody const & changes)
inline

Applies a changes event's payload to the cache, in one reactive batch.

A record change with keys marks each entry holding the record whose value has a row with one of the keys, and an entry holding it keyless; a record change without keys marks every entry holding the record. An instance change marks every entry read through that instance: the keyed shared one its primary key names, or, with no primary key, the connection's own private ones of that model type.

Parameters
changesThe payload.

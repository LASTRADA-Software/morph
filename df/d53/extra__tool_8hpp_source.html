34/// @brief What an extra tool is told about the turn that may call it.
35///
36/// Everything in it comes from the verified session or from the client's `TurnRequest`, which is a hint: a tool treats
37/// the request's fields, and above all its draft, as data a person or a document's author may have written, and
38/// checks what it does under `session`.
39struct ChatToolContext {
40 /// @brief The turn's session, its principal verified.
41 session::Context session;
42 /// @brief The screen the person is on: its id, title, identity, params, models and draft, and what they said.
43 TurnRequest request;
44 /// @brief The document the turn is working on, as JSON text: the latest draft a tool accepted in this turn, else
45 /// the draft the request carried; absent when neither exists, in which case the screen's own document is
46 /// where the turn started (`bundle`, `external`). A tool that reads or patches the screen reads this, so
47 /// a call sees what the calls before it accepted.
48 std::optional<std::string> document;
49 /// @brief The bundle the chat serves, which is where an application screen's own document is read.
50 std::shared_ptr<ServedBundle const> bundle;
51 /// @brief The chat's bounds.
52 ChatLimits limits;
53 /// @brief What `ChatOptions::documentSource` read for the open screen, when the bundle does not hold it. It is
54 /// read once per turn, so a tool does not read the screen again.
55 std::optional<ChatScreenSource> external;
56 /// @brief How many earlier calls of this tool, in this turn, came back as an error.
57 std::size_t failedCalls = 0;
58 /// @brief Whatever the tool's `offer` handed to `ChatToolOffer::carried`; null without one.
59 std::shared_ptr<void const> carried;
60};
61
62/// @brief What a tool answers when it is asked whether this turn may call it.
63struct ChatToolOffer {
64 /// @brief Whether the tool is offered to the model in this turn.
65 bool offered = false;
66 /// @brief Text appended to the turn's system text, whether or not the tool is offered; empty for none. It is the
67 /// place to say what the tool is for, and, when it is not offered, why the assistant cannot do this.
68 std::string system;
69 /// @brief Whatever the tool's handler needs again from the work this answer took; reaches it as
70 /// `ChatToolContext::carried`.
71 std::shared_ptr<void const> carried;
72};
73
74/// @brief What a tool call came to.
75struct ChatToolOutcome {
76 /// @brief What the model is told: the result's text, or why the call did not run.
77 std::string text;
78 /// @brief Whether the call failed. A failure is counted in `ChatToolContext::failedCalls` of later calls.
79 bool isError = false;
80 /// @brief A document the call accepted as the screen's draft: it becomes `TurnState::draft` and goes out as a
81 /// `draft` event. A tool sets it only for a document it has checked; a failed call's draft is dropped.
82 std::optional<std::string> draft;
83 /// @brief Set to end the turn after this call: the turn fails with this text, which the person reads. The call's
84 /// own result is recorded first.
85 std::optional<std::string> stop;
86};
87
88/// @brief Where a handler delivers a call's outcome: from any thread, exactly once. A second delivery is ignored. A
89/// turn that stopped meanwhile ignores it too. A handler that has not delivered within
90/// `ChatLimits::toolCallTimeout` is answered with a failed outcome, and a later delivery is ignored.
91using ChatToolDone = std::function<void(ChatToolOutcome)>;
92
93/// @brief Where an offer delivers its answer: from any thread, exactly once.
94using ChatToolOfferDone = std::function<void(ChatToolOffer)>;
95
96/// @brief Runs one call of a tool.
97///
98/// Invoked on the turn's worker with the context by value, so a handler that finishes later keeps it. The arguments
99/// are a JSON object: the service refuses any other call before it gets here. A handler that never delivers is
100/// answered as failed after `ChatLimits::toolCallTimeout`, and one that throws reports the call as failed.
101using ChatToolHandler = std::function<void(ChatToolContext, Json, ChatToolDone)>;
102
103/// @brief Answers whether this turn may call a tool, once at its start. Invoked on the turn's worker. An offer that
104/// has not answered within `ChatLimits::toolCallTimeout` counts as declined.
105using ChatToolOfferer = std::function<void(ChatToolContext, ChatToolOfferDone)>;
106
107/// @brief Rewrites a call's arguments into what the conversation keeps of it; sees the arguments as JSON text and
108/// answers JSON text for an object.
109using ChatToolRecord = std::function<std::string(std::string const&)>;
110
111/// @brief A tool added to a chat.
112///
113/// Its name is what the model calls it by: 1 to 64 characters of letters, digits, `_` and `-`, with no `__`, which
114/// is what a screen's own tools' names carry, so the two kinds cannot be confused. Two tools of one chat cannot share
115/// a name. `ChatService` refuses a tool that breaks either rule when it is built.
116struct ChatTool {
117 /// @brief What the model is offered: its name, what it does and the schema of its arguments.
118 ToolSpec spec;
119 /// @brief Whether this turn offers the tool. Empty: always offered, with nothing added to the system text.
120 ChatToolOfferer offer;
121 /// @brief What a call does. Required.
122 ChatToolHandler handler;
123 /// @brief What the conversation keeps of a call's arguments, so a large argument is not carried through later
124 /// turns. Empty keeps them as the model wrote them. The turn itself still sees the whole call, and a
125 /// provider's own replay of a message with a rewritten call is dropped from the conversation.
126 ChatToolRecord record;
127};

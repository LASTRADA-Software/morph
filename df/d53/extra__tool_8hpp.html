◆ ChatToolHandler

using morph::ui::chat::ChatToolHandler = std::function<void(ChatToolContext, Json, ChatToolDone)>

Runs one call of a tool.

Invoked on the turn's worker with the context by value, so a handler that finishes later keeps it. The arguments are a JSON object: the service refuses any other call before it gets here. A handler that never delivers is answered as failed after ChatLimits::toolCallTimeout, and one that throws reports the call as failed.

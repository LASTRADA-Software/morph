Detailed Description

template<typename T, FixedString OptionsAction, FixedString ValueField = "id", FixedString LabelField = "name">
struct morph::forms::Choice< T, OptionsAction, ValueField, LabelField >

An optionally-empty value selected from options served by another action.

Template Parameters
TUnderlying value type submitted on the wire (e.g. std::int64_t for ids, std::string for codes).
OptionsActionType id of the registered action whose result provides the options (executed with an empty body).
ValueFieldField of each result row submitted as the value.
LabelFieldField of each result row shown to the user.

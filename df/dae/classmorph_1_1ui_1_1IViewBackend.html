Detailed Description

Makes widgets. Each factory appends the new widget to parent, or makes a root when it is null, and never returns null, except createCustom, whose null shows a custom node's fallback.

CustomRequest const & request )
inlinenodiscardvirtual

Loads the component a custom node names, if this backend can. The only factory that may return null: null means "not loaded", and the mount shows the node's fallback instead. A backend that loads no components keeps this default.

Parameters
parentThe container to append it to; null makes a root.
requestThe component, the props the document declares and the host component's lowest version.
Returns
The component, or null to show the fallback.

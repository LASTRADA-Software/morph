MORPH_API std::optional< std::size_t > morph::ui::pointerOffset ( std::string_view text,
std::string_view pointer )
nodiscard

Where the part a JSON Pointer names starts in text.

The text is scanned, not parsed into a value, so the offset is into the text as it is, with its own spacing and member order. For a member, the offset is that of its name's opening quote, where a person looks for it; for an array element, that of the element's first byte. Of equal member names the last counts, as it does in the parsed value. The empty pointer answers the first byte that is not white space, whether or not the text is JSON; a byte order mark before the document is not white space, so a non-empty pointer finds nothing after one.

Parameters
textJSON text.
pointerAn RFC 6901 pointer; ~0 and ~1 are unescaped.
Returns
The byte offset, or std::nullopt when the pointer names nothing in text, text is not JSON up to that part, the pointer is not one, or it reaches deeper than kMaxJsonDepth.

Detailed Description

template<typename T = Any>
class morph::ui::author::Handle< T >

An expression of a document, typed by the C++ value it evaluates to (spec 5 §11).

A handle is a JSON expression tree. Operators build calls of the expr/1 library: a + b is add, a < b is lt, a && b is and, !a is not; at reads a field by member pointer, and orElse is coalesce. A default-constructed handle is absent: a builder leaves out the key it would fill.

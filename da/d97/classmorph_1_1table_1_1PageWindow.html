Detailed Description

template<typename Row>
class morph::table::PageWindow< Row >

The pages a server-mode table holds: those around the visible rows, up to a bound, plus the request state and the last error.

The client calls visible as the view scrolls and sends the request of each fetch it returns, then hands the fetch back with its reply to accept (or with its error to fail). A change of sort or filter is a new query: call reset. A reply to a fetch made before the last reset is ignored, so a late page of the old query never shows under the new one.

A server may return fewer rows than a fetch asked for (validate clamps the limit to its maxLimit): the window then fetches the rest of the page from where the reply ended. A page is complete when it is full, reaches the known total, or a reply to it is empty.

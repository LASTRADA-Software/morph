Detailed Description

One mounted screen, as its host sees it.

The host reads title, dirty and identity to show the tab and the unsaved indicator, and closes the screen through requestClose. It never destroys a handle whose close is pending, except after forceClose.

◆ save()

virtual void morph::ui::ScreenHandle::save ( std::function< void(bool clean)> done)
inlinevirtual

Saves the screen's changes (spec 6 §15) and answers whether it is then clean.

A document screen runs onSave, waits until nothing pending is left, and answers true when dirty is then not true. A save while one waits joins it. A screen that cannot save answers false at once. done is not called when the screen closes before the save has finished.

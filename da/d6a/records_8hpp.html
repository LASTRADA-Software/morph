Detailed Description

The registry of record types: the rows a server can push changes about.

A record is a plain reflected struct identified by a key member. Registration is a static registrar, like an action's, so it is checked by the same registration-phase latch. The registry stores what was declared; cross-entry validation (duplicate names, derivation cycles, keyless records that an effect names) happens when the registry is read for matching, not here.

Registers a record type under a wire name, with optional key, derivation and privacy options.

The key defaults to the member reflected as id. Options are morph::record::key<&T::m>, morph::record::keyless, morph::record::derivedFrom<S...> and morph::record::privateKeys. Expands to nothing under MORPH_CLIENT_ONLY.

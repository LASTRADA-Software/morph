std::function< bool()> tryReconnect
 Attempt to (re)open the primary backend.
 
std::function< void()> activatePrimary
 Make the freshly-reconnected primary the active backend. Called exactly once per successful onOnline(), after tryReconnect() succeeds and before bindContext().
 
std::function< void()> activateLocal
 Switch the active backend to the local/offline one. Called by onOffline(). Followed by bindContext() so context tracks the now-active backend.
 
std::function< void()> bindContext
 Rebind per-connection / per-session context to the active backend. Called after every activate* step. Must not throw.
 
std::function< void()> replay
 Replay the offline queue against the now-active primary. Typically wraps SyncWorker::run(). Called last in onOnline().
 
std::function< bool()> shouldContinue
 Returns false to abort the current onOnline() sequence early (e.g. the monitor reports the backend went offline again mid-retry). Polled before each reconnect attempt and once more before replay.
 
std::function< void(std::chrono::milliseconds)> sleep
 Sleep for the given duration between failed attempts. Injected so tests can substitute a no-op / counter. Hosts wire this to std::this_thread::sleep_for.

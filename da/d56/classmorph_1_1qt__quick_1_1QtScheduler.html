Detailed Description

reactive::Scheduler on QTimers, for a runtime whose owner is the Qt event loop's thread.

Each callback runs on that thread with owner as the current executor, so it may write the reactive state the owner's runtime holds. It keeps every guarantee of the Scheduler contract: a cancelled timer never fires; a handle may be cancelled from inside its own callback and may outlive the scheduler; a periodic timer that the loop could not serve for several periods fires once. Neither copyable nor movable; used on its thread only.

Detailed Description

template<typename Sharing, typename... Model>
class morph::qt::forms::MultiModelFormsControllerCore< Sharing, Model >

DynamicForm.qml-facing facade over morph::qt::bridge::MultiModelBridgeCore, naming its one routed dispatch operation submitIfValid/fetchOptions instead of execute, and carrying the {actionType: schema} document DynamicForm.qml renders from – a forms-specific concept the composed core deliberately does not know about.

Template Parameters
SharingForwarded to MultiModelBridgeCore unchanged. Named first, for the same reason MultiModelBridgeCore documents on its own Sharing parameter: it precedes a variadic pack, which must be the last template parameter, so it cannot also carry a usable default.
ModelTwo or more registered model types (BRIDGE_REGISTER_MODEL) whose actions the shipped DynamicForm.qml renders, in the order their handlers are tried when routing an action-type id.

Detailed Description

Keeps the route of the screen a shell shows in a history, and opens the route of an entry the user moves to (spec 3 §10).

The shell opens initial() first, when it can, and calls shown after it mounts each screen. The first shown replaces the entry the history started on, so opening the first screen does not add a step back to an empty page; each later call adds an entry, unless the route is already the current entry's. Moving back or forward calls open, which shows the route's screen, or the start screen when the route cannot be opened, before it returns. The first screen it shows replaces the entry instead of adding one, so a refused route is not left in the history; a screen shown after that, such as a redirect, adds an entry as it would anywhere else.

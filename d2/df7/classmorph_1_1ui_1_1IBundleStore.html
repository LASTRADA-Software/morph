Detailed Description

Where a client keeps verified files between runs, by content hash, and the digest of each application's last verified bundle.

A store is not trusted: VerifiedCache hashes what it reads back. A client calls it from whichever thread its exchange calls back on, and runs of several opens may overlap, so an implementation is safe to call from any thread.

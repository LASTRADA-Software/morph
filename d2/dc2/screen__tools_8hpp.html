The tools of one screen: each query, mutation and model-bound node the document names, at any scope, whose alias the context bound and whose action the principal may run.

A tool is named <alias>__<action>. A name a provider's tool format would refuse, or one a tool already took, gets a shortened stem and a hash of its scope, alias and action, so it stays valid and unique. The tools are sorted by name, and an action named more than once on one alias gives one tool, offered as changing data if any naming runs it as a mutation. A credential action gets no tool: a model should not be handed a password to pass along.

Parameters
documentThe screen's document, loaded.
modelsThe aliases the client says it holds. One counts only if its scope, alias and type all match the document's declaration, so a context cannot point a tool at a model the screen does not declare.
permittedThe actions the principal may run.
schemasEach action's schema, by action id.
actionsThe catalog's action facts, when there are any.
Returns
The tools.

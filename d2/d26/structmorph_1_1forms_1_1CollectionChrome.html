Replacements for the parts of a collection view a host draws from its own UI kit. Each one left empty keeps the built-in part. More...

#include <collection_view.hpp>

Public Attributes

std::function< ui::Node(CollectionSession &)> header
 Replaces the title and the collection actions' buttons. Called once, with the session, whose model gives the title, columns and actions and whose fire runs one.
std::function< ui::Node(CollectionSession &, reactive::Signal< CollectionRow > const &)> row
 Replaces each row's cells and buttons: the rows are then a list of these nodes rather than a table. Called once per row mounted, with the session and the row's signal (read it inside bindings).
std::function< ui::Node(CollectionSession &)> confirm
 Replaces the confirm dialog: mounted while an action waits for confirmation, unmounted once it is answered. Called with the session, whose pendingConfirm, confirm and cancelConfirm it uses.
std::function< ui::Node(CollectionSession &, ui::Node editor)> editor
 Replaces the editor dialog of a collection view; it is always mounted, and shows the editor while openRow() is engaged. Called once with the session and the editor's form view, which it places. A master-detail view has no dialog and does not call it.

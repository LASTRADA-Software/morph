33/// @brief The QML components a client renders beside the built-in kinds (spec 5 §10).
34///
35/// - A **host component** is QML the client carries, registered by name and version. It loads into the backend's
36/// own engine, so it may import the application's other modules.
37/// - A **bundle component** is QML text delivered in the application's bundle and named by its SHA-256 digest. It
38/// loads only when the text matches the digest, and compiles in a dedicated engine whose root context holds
39/// nothing, so it sees nothing but what is set on it.
40/// - The **restyle map** names a component for a built-in kind. The component must declare every property and
41/// function of the kind's `MorphUi` component; one that does not is refused when it is mapped.
42///
43/// Each component reports its events through `host.fire(event, payload)`, `host` being a `var` property it declares
44/// and the renderer sets. A component that fails to load is reported once, through the callback, and the caller
45/// renders its fallback. Neither copyable nor movable; it outlives every backend that uses it.
46class Components {
47public:
48 /// @brief An empty set.
49 /// @param report Called once for each component that fails to load, or restyle that is refused; may be empty.
50 explicit Components(std::function<void(ComponentFailure const&)> report = {});
51 /// @brief Releases the compiled components and the contained engine.
52 ~Components();
53 Components(Components const&) = delete;
54 Components& operator=(Components const&) = delete;
55 Components(Components&&) = delete;
56 Components& operator=(Components&&) = delete;
57
58 /// @brief Registers a host component, replacing one of the same name.
59 /// @param name The name a document uses.
60 /// @param version The version the client carries; a document asking for a later one gets the fallback.
61 /// @param source The QML file, such as a `qrc:` URL.
62 void addHost(std::string name, int version, QUrl const& source);
63
64 /// @brief Registers a bundle component, replacing one of the same name.
65 /// @param name The name a document uses.
66 /// @param qml The QML text, as the bundle delivered it.
67 /// @param digest Its SHA-256, as the bundle names it: `sha256:` followed by 64 hexadecimal digits.
68 // NOLINTNEXTLINE(bugprone-easily-swappable-parameters): a name, its text and its digest, as the bundle lists them.
69 void addBundle(std::string name, std::string qml, std::string digest);
70
71 /// @brief Maps a built-in kind to a registered component, checking that the component declares every property
72 /// and function of the kind's `MorphUi` component.
73 /// @param engine The engine the backend renders with. Borrowed for the call.
74 /// @param kind The kind as a document names it: `button`, `textInput`, `checkbox`, `select`, …
75 /// @param component The registered component's name.
76 /// @return Nothing, or why the mapping is refused; a refusal is also reported, and the kind keeps its
77 /// `MorphUi` component.
78 // NOLINTNEXTLINE(bugprone-easily-swappable-parameters): a kind, then what restyles it, as the bundle maps them.
79 [[nodiscard]] std::expected<void, ComponentFailure> restyle(QQmlEngine& engine, std::string const& kind,
80 std::string const& component);
81
82 /// @brief The compiled component a restyle maps a `MorphUi` type to, for a backend to instantiate.
83 /// @param engine The backend's engine. Borrowed for the call.
84 /// @param type The `MorphUi` type, such as `MorphButton`.
85 /// @return The component, or null when the type is not restyled.
86 [[nodiscard]] std::unique_ptr<QQmlComponent> restyled(QQmlEngine& engine, std::string const& type);
87
88 /// @brief Compiles a registered component, or says why it cannot be used.
89 /// @param engine The backend's engine, which host components load into. Borrowed for the call.
90 /// @param name The component's name.
91 /// @param minVersion The lowest host component version that will do.
92 /// @return The compiled component, owned by this set, or the failure, which is also reported once.
93 [[nodiscard]] std::expected<QQmlComponent*, ComponentFailure> load(QQmlEngine& engine, std::string const& name,
94 int minVersion = 0);
95
96 /// @brief Reports a failure, once per name and reason.
97 /// @param failure The failure.
98 void report(ComponentFailure const& failure);
99
100 /// @brief Every failure reported so far, oldest first.
101 /// @return They.
102 [[nodiscard]] std::vector<ComponentFailure> const& failures() const noexcept;
103
104private:
105 struct State;
106 std::unique_ptr<State> _state;
107};

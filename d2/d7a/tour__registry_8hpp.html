Detailed Description

Guided tours registered while the server runs: TourRegistry, the morph.tours model that lists them, and the wiring that tells watching clients when they change. Specified in docs/spec/ui/tours.md.

MORPH_API void morph::ui::registerTours ( std::shared_ptr< TourRegistry > tours,
std::shared_ptr<::morph::session::IAuthorizer const > authorizer,
model::detail::ActionDispatcher & dispatcher,
model::detail::ModelRegistryFactory & registry )

Registers the runtime tours model and its list action, with a factory that gives every instance the one registry. A server calls it once, before it serves. A server that does not answers list with the dispatcher's unknown-model error, which a client reads as "the app document's tours alone".

Parameters
toursThe registry.
authorizerThe server's authoriser.
dispatcherThe server's action dispatcher.
registryThe server's model registry.
Exceptions

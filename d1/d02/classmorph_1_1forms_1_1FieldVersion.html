Detailed Description

A dotted numeric version such as 6.11.0, ordered component by component.

The value means nothing to morph apart from its order. Components are compared from the left as unsigned numbers, and a missing trailing component counts as 0, so 6.11 and 6.11.0 are equal and 6.11 is below 6.11.1. A default-constructed version is the first version, written 0: what a field or an element without a since belongs to, and below every version that has a non-zero component.

inlinestaticnodiscard

Parses a dotted numeric version.

The text is one or more components separated by single dots. Each component is decimal digits, without a leading zero unless it is 0 itself (so 6.01 cannot silently equal 6.1), and at most 4294967295. The whole text is at most kMaxTextBytes bytes. Anything else is refused.

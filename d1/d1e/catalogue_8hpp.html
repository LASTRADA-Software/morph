◆ parseCatalogue()

std::expected< Catalogue, std::string > morph::ui::parseCatalogue ( std::string_view text)
inlinenodiscard

Parses a catalogue: a flat JSON object of message key to MessageFormat 2 pattern.

Refused: text that is not JSON or nests deeper than kMaxJsonDepth, anything but an object, a must-understand (!) key, a value that is not a string, an empty key or one longer than kMaxNameBytes, and more than kMaxCatalogueKeys keys. A pattern outside the ui/1 subset does not refuse the catalogue: its key is left out and listed in dropped, so t shows the fallback for it.

Parameters
textThe catalogue's JSON text.
Returns
The catalogue, or the reason it is refused.

◆ catalogTitle()

std::string morph::ui::catalogTitle ( CatalogEntry const & entry,
MessageCatalogues const * catalogues,
std::string_view locale )
inlinenodiscard

A catalog entry's title in one locale, as a shell's tab or header shows it.

A string title is shown as is. A message reference ({"t": key, "fallback": …}) is formatted in locale from catalogues — the exact locale's catalogue, then its language's — and is its fallback when no catalogue has the key. A title that is neither, or a reference with no fallback that no catalogue resolves, is the entry's id.

Parameters
entryThe entry.
cataloguesThe message catalogues, or null for none.
localeThe BCP 47 locale to format in.
Returns
The title.

Detailed Description

Server-side authoring of UI documents (spec 5 §11): typed builders that write a screen's JSON, and the registration that validates it once — loadDocument with the builders' catalog facts, then the accessibility rules.

The builders live in morph::ui::author, beside the view-tree builders of morph::ui that share their names; a screen's source writes namespace ui = morph::ui::author;. Specified in docs/spec/ui/author.md.

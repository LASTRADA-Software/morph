Detailed Description

Stores customization choices as JSON text, by PrefKey.

Every call is asynchronous, so a store may sit on a database or a remote service. A store owns the executor its completions are delivered on. The preferences model calls it only with keys whose person the server derived and with values it has already bounded and parsed, so a store applies no bound of its own.

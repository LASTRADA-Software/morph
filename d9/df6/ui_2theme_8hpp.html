Detailed Description

Theme tokens (ui-theme/1, spec 6 §6): DTCG 2025.10 token files read and checked, layered into a variant, their aliases resolved, and the closed ui-theme/1 set filled from them with its defaults. No toolkit: the Qt Quick renderer applies the result (qt_quick::applyTheme).

Specified in docs/spec/ui/theme.md.

◆ parseTokens()

std::expected< TokenSet, std::string > morph::ui::parseTokens ( std::string_view text)
inlinenodiscard

Parses a DTCG 2025.10 token file.

Groups nest; a token is an object with $value, and its $type is its own or the nearest group's. Refused: text that is not a JSON object or nests deeper than kMaxJsonDepth, a must-understand (!) name, a name with ., { or }, a member that is not an object, a token with no type that is not a plain alias, a value that does not have its checked type's shape, $extends, and more than kMaxThemeTokens tokens. A token of a $type the client does not know is dropped.

Parameters
textThe file.
Returns
The tokens by path, aliases unresolved, or why the file is refused.

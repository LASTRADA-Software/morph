Detailed Description

Theme tokens (ui-theme/1, spec 6 §6): DTCG 2025.10 token files read and checked, layered into a variant, their aliases resolved, and the closed ui-theme/1 set filled from them with its defaults. No toolkit: the Qt Quick renderer applies the result (qt_quick::applyTheme).

Specified in docs/spec/ui/theme.md.

enum class morph::ui::ThemeTokenKind : std::uint8_t
strong

What a ui-theme/1 token is read as.

Enumerator
Color 

A color token.

Number 

A number token.

Dimension 

A dimension token, read in px (a rem is 16 px).

Shadow 

A shadow token: a colour and four px lengths; of a list of layers, the first.

FontFamily 

A fontFamily token: a family name, or a list of them in order of preference.

FontWeight 

A fontWeight token, read as its numeric weight, 1 to 1000, in ThemeValues::numbers.

Stroke 

A strokeStyle token: solid or dashed, in ThemeValues::strokes.

Keyword 

A keyword token: one of the names the spec lists, in ThemeValues::keywords.

◆ parseTokens()

std::expected< TokenSet, std::string > morph::ui::parseTokens ( std::string_view text)
inlinenodiscard

Parses a DTCG 2025.10 token file.

Groups nest; a token is an object with $value, and its $type is its own or the nearest group's. Refused: text that is not a JSON object or nests deeper than kMaxJsonDepth, a must-understand (!) name, a name with ., { or }, a member that is not an object, a token with no type that is not a plain alias, a value that does not have its checked type's shape, $extends, and more than kMaxThemeTokens tokens, and a token that holds members of its own: write it as a group whose $root member is the token. A group's $root is the token at the group's own path, and an alias may name it either as {a.b} or as {a.b.$root}. A token of a $type the client does not know is kept unchecked with its type, which unreadThemeTokens names.

Parameters
textThe file.
Returns
The tokens by path, aliases unresolved, or why the file is refused.

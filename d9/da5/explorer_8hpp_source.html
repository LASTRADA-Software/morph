40/// @brief What names an action in a document.
41enum class ActionUseKind : std::uint8_t {
42 Query, ///< A query declaration.
43 Mutation, ///< A mutation declaration.
44 Form, ///< A `form` node.
45 Collection, ///< A `collection` node.
46 Wizard, ///< A `wizard` node.

49/// @brief The name of an action use's kind.
50/// @param kind The kind.
51/// @return `"query"`, `"mutation"`, `"form"`, `"collection"` or `"wizard"`.
52[[nodiscard]] constexpr std::string_view actionUseKindName(ActionUseKind kind) noexcept {
53 constexpr std::array<std::string_view, 5> kNames{"query", "mutation", "form", "collection", "wizard"};
54 return kNames.at(static_cast<std::size_t>(kind));

69/// @brief Every place a loaded document names an action: its queries and mutations at any scope, and its `form`,
70/// `collection` and `wizard` nodes, in document order.
71///
72/// A model type is the alias's, from the nearest enclosing scope that declares it. An alias that borrows another has
73/// no type in the document, and takes the catalog's `ActionInfo::modelType`. A `run` command names a mutation, not an
74/// action, so it is no use of its own.
75/// @param document The document: a screen, or the app document.
76/// @param catalog The facts a borrowed alias's model type is read from; empty leaves such a type empty.
77/// @return The uses.

113/// @brief The one-node document "Try it" mounts for an action.
114///
115/// A private instance of the model under the alias `target`, the states `reply` and `failure`, and a column holding
116/// the node over the action (test id `tryit`) and, for a form, two texts showing the states (`tryit_result`,
117/// `tryit_error`). A form submits from its button only, and its `onSuccess` and `onError` set the states; a
118/// collection and a wizard show their own results and errors.
119/// @param actionId The action id.
120/// @param modelType The model type the action belongs to.
121/// @param kind The node.
122/// @return The document's JSON text, with the id `tryItScreenId(actionId)`.
123// NOLINTNEXTLINE(bugprone-easily-swappable-parameters): an action id and a model type read alike, and neither reads.
124[[nodiscard]] MORPH_API std::string tryItDocument(std::string_view actionId, std::string_view modelType,
125 TryItKind kind);

163/// @brief The app explorer, as a host screen (spec 6 §15): a splitter with the list — a search, the catalog's

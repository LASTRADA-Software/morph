◆ actionUses()

std::vector< ActionUse > morph::ui::actionUses ( Document const & document,
Catalog const & catalog = {} )
inlinenodiscard

Every place a loaded document names an action: its queries and mutations at any scope, and its form, collection and wizard nodes, in document order.

A model type is the alias's, from the nearest enclosing scope that declares it. An alias that borrows another has no type in the document, and takes the catalog's ActionInfo::modelType. A run command names a mutation, not an action, so it is no use of its own.

Parameters
documentThe document: a screen, or the app document.
catalogThe facts a borrowed alias's model type is read from; empty leaves such a type empty.
Returns
The uses.

◆ tryItDocument()

std::string morph::ui::tryItDocument ( std::string_view actionId,
std::string_view modelType,
TryItKind kind )
inlinenodiscard

The one-node document "Try it" mounts for an action.

A private instance of the model under the alias target, the states reply and failure, and a column holding the node over the action (test id tryit) and, for a form, two texts showing the states (tryit_result, tryit_error). A form submits from its button only, and its onSuccess and onError set the states; a collection and a wizard show their own results and errors.

Parameters
actionIdThe action id.
modelTypeThe model type the action belongs to.
kindThe node.
Returns
The document's JSON text, with the id tryItScreenId(actionId).

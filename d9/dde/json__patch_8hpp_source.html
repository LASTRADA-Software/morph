17/// @brief @p document with the RFC 6902 operations of @p patch applied in order.
18///
19/// Either every operation applies and the patched document is returned, or none does and the refusal names the first
20/// one that failed. Each operation is one of `add`, `remove`, `replace`, `move`, `copy` and `test`; `add` and
21/// `replace` and `test` carry a `value`, `move` and `copy` a `from`, and every operation a `path`. The path `""` is
22/// the whole document. A path that does not exist is refused, and no intermediate container is made for it.
23/// @param document The document to patch, taken by value so the caller's copy is untouched.
24/// @param patch A JSON array of operation objects; an empty array changes nothing.
25/// @return The patched document, or a refusal: `op N is not a JSON object` or `op N: ...` for an operation that is
26/// malformed, and `op N (name path): ...` for one that cannot be applied, with N counted from 0. A @p patch
27/// that is not an array is refused with a message of its own.
28[[nodiscard]] MORPH_API std::expected<Json, std::string> applyJsonPatch(Json document, Json const& patch);
29
30/// @brief An RFC 6902 patch that turns @p before into @p after.
31///
32/// Objects are compared member by member and arrays element by element, so a change deep in a document is one
33/// operation at its own pointer: a member only in @p before is a `remove`, one only in @p after an `add`, a value of
34/// another kind or another scalar a `replace`. An array that grew gets an `add` for each element past the old end, in
35/// order; one that shrank gets a `remove` for each element past the new end, last first, so every index named is the
36/// one the operation finds. An element moved within an array or a member moved between parents is reported as the
37/// removal and the addition it amounts to; no `move` or `copy` is produced. Pointer tokens escape `~` as `~0` and `/`
38/// as `~1`.
39/// @param before The document the patch starts from.
40/// @param after The document the patch ends at.
41/// @return A JSON array of operations: empty when the documents are equal, and otherwise one that
42/// `applyJsonPatch(before, patch)` turns back into @p after.
43[[nodiscard]] MORPH_API Json diffJson(Json const& before, Json const& after);

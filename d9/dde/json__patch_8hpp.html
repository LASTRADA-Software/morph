MORPH_API std::expected< Json, std::string > morph::ui::applyJsonPatch ( Json document,
Json const & patch )
nodiscard

document with the RFC 6902 operations of patch applied in order.

Either every operation applies and the patched document is returned, or none does and the refusal names the first one that failed. Each operation is one of add, remove, replace, move, copy and test; add and replace and test carry a value, move and copy a from, and every operation a path. The path "" is the whole document. A path that does not exist is refused, and no intermediate container is made for it.

Parameters
documentThe document to patch, taken by value so the caller's copy is untouched.
patchA JSON array of operation objects; an empty array changes nothing.
Returns
The patched document, or a refusal: op N is not a JSON object or op N: ... for an operation that is malformed, and op N (name path): ... for one that cannot be applied, with N counted from 0. A patch that is not an array is refused with a message of its own.

MORPH_API Json morph::ui::diffJson ( Json const & before,
Json const & after )
nodiscard

An RFC 6902 patch that turns before into after.

Objects are compared member by member and arrays element by element, so a change deep in a document is one operation at its own pointer: a member only in before is a remove, one only in after an add, a value of another kind or another scalar a replace. An array that grew gets an add for each element past the old end, in order; one that shrank gets a remove for each element past the new end, last first, so every index named is the one the operation finds. An element moved within an array or a member moved between parents is reported as the removal and the addition it amounts to; no move or copy is produced. Pointer tokens escape ~ as ~0 and / as ~1.

Parameters
beforeThe document the patch starts from.
afterThe document the patch ends at.
Returns
A JSON array of operations: empty when the documents are equal, and otherwise one that applyJsonPatch(before, patch) turns back into after.
